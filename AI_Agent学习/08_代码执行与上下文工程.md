## 📚 核心知识点

### 1. 第二种手：代码解释器

03 篇的工具是人预先写好的函数：搜索、计算器、天气。还有一种更宽的手：模型写一段程序，你跑完，把标准输出塞回上下文。

它适合临时计算、表格处理和格式变换。它不适合当默认工具。能用一个参数清晰的函数解决的，不要让模型现写脚本——脚本的失败形态更多，权限也更难收。

一次循环仍然是老三步：

```
思考：模型决定写一段代码
行动：你的程序在沙箱里执行这段代码
观察：stdout / stderr 追加进 messages，再给模型
```

`practice/agent08_code_sandbox.py` 的任务 1 就是这个观察：代码打印 `2.41`，这个字符串就是下一步能看见的事实。

### 2. 沙箱要挡住的是四件不同的事

| 风险 | 这一课用什么挡 | 挡不住什么 |
|---|---|---|
| 弄垮 Agent 自己的进程 | 子进程。用户代码崩了，主进程还在 | 子进程仍然可以读你允许它读的磁盘 |
| 死循环把机器占满 | `timeout`。练习里 0.5 秒就放弃等待 | 超时只保证你不再等，生产环境还要确认子进程被杀掉 |
| 明显的危险写法 | 源码里出现 `import`、`open(`、`eval(`、`__` 就拒绝 | 字符串黑名单可以被绕过，不能当唯一防线 |
| 不该碰的数据 | 少给权限：只读目录、禁网、单独的系统用户 | 练习没有做这一层，任务 4 专门演示缺口 |

任务 4 把静态检查关掉之后，`import os; print(os.name)` 在子进程里能跑完，只打印操作系统名字。这说明：**子进程隔离的是「别搞垮我」，不是「不许碰系统」。** 同一段不检查的代码也可以去读文件。上线至少要：静态检查（知道它很弱）+ 超时 + 子进程 + 目录和网络权限。

### 3. 代码工具的观察怎么写回

执行完只回灌短结果，不要回灌整段日志。建议固定四行：

```text
exit_code: 0
stdout: 2.41
stderr: （空）
截断说明: 无
```

失败也要回灌。`stderr` 里的 `SyntaxError`、超时、静态检查拒绝，都是模型改写下一版代码的依据。直接把异常抛出循环，模型没有机会改。这和 03 篇「工具报错要写回」是同一条规则。

再加两条刹车：

- 同一段代码连续失败两次，就停止再生成，改向用户说明差什么
- 单次任务里代码执行不超过 5 次，防止它用试错刷爆时间

### 4. 上下文工程：这一轮到底放什么

05 篇讲了窗口满了怎么压缩。这里补「还没满的时候，这一轮该放什么」。放进去的每一段都会被模型当成可执行的信息，也会花钱。

每一轮按这个顺序组装，缺的不要用空话填：

```text
1. 系统角色：你是谁、不能做什么、危险操作必须停
2. 工具清单：只放这一轮允许用的工具的 Schema。服务端有删除，不代表这里要列出删除
3. 检索到的资料：用标记包起来，声明标记内是数据不是指令
4. 任务状态：目标、已经确认的事实、未完成的一步。压缩后留下的就是这块
5. 最近几轮的工具结果：旧的大段原文不要原样留着
6. 用户最新的一句话
```

判断标准就一句：**拿掉这段，下一步会不会做错？** 会，留下。不会，拿掉。

### 5. 压缩前后各长什么样

压缩不是「让模型写一段摘要」就结束。摘要要能接着干。下面这份就够用：

```text
目标：算特斯拉营收同比
已确认：本季 255 亿美元；去年同期 249 亿美元
已做：search 成功；calculator 尚未调用
不要再做：不要重复刚才那次 search
未完成：调用 calculator，表达式 (255-249)/249*100
```

对比被丢掉的内容：搜索引擎返回的整页、模型中间那句「我先查一下」。下一步只需要事实和未完成项。

`practice/agent05_pipeline.py` 是同一原则的多智能体版本：研究员上下文约 820 字，写手只收到 151 字的结论。整段转交大约 5.6 倍。子任务交回的应该是这种结论，不是父任务的全部历史。

### 6. 和毕业项目怎么接

个人助理里，「算一下」「把这段整理成表格」可以走代码工具；「查笔记」走 04 篇的检索工具；「删文件、发消息」不走代码工具，走单独的函数，并且执行前等人确认。代码工具的工作目录用一个空的临时文件夹，不要指向你的笔记仓库。

## 🔬 原理

### 注意力的权重和为 1，多放的材料会挤占该看的材料

一个注意力头里，某个位置对前面各位置的权重来自 softmax，因此这些权重非负且和为 1。设相关 token 原来分到的权重是 \(a\)。你再塞进一大段无关文本，新的 softmax 要在更多位置上重新归一，相关位置的权重变成比 \(a\) 更小的 \(a'\)。无关文本不是「另外附赠的阅读」，它占用的是同一份权重。

这是上下文取舍的机制，费用只是同一件事的账单。标准自注意力下，序列长度 \(n\) 的一次前向，注意力计算量大约随 \(n^2\) 增长。塞进检索原文、旧的工具输出、客套话，同时在付计算、在稀释权重。

「拿掉这段，下一步会不会做错」就是在问：这些 token 会不会改变 \(p(\text{下一步}\mid x)\) 的峰值。会，它们才配分享那份和为 1 的权重。子 Agent 只交回结论，是在父序列里用几十个 token 代替几百个 token，把权重留给结论和用户的目标。

位置还会再偏一次。模型习惯任务说明在最前、当前问题在最后，中间的长文更容易被弱化（04 篇的 lost in the middle）。所以顺序不是排版：系统约束靠前，当前问题和刚检索到的短证据靠后贴在一起，旧观察放中间而且要短。

### 代码工具改的是环境转移，不是模型的策略

模型写出 `print(...)` 时，仍然只是 \(p(\text{代码}\mid x)\) 的一次采样。沙箱不修改这个分布。沙箱修改的是：这段文本作为动作，环境允许它造成哪些转移。

用强化学习的记号，策略 \(\pi\) 和环境转移 \(P(s'\mid s,a)\) 是分开的。静态检查、超时、工作目录、禁网，都写在转移里：某些动作的后继状态是「被拒绝」，而不是「操作系统已经执行完」。主进程和子进程的边界，是让用户代码的崩溃不要变成 Agent 进程这个状态的转移。它没有改写 \(\pi\)，也没有禁止子进程里一切系统调用——那要靠你给这个进程的权限，也就是进一步限制 \(P\)。

所以 03 篇的白名单函数和这里的代码工具是同一套原理的两个动作空间。函数工具的动作空间小，每个动作的转移是你手写的，\(p\) 好保持。代码工具的动作空间是一门语言里的程序，表达力大，转移必须在外面收紧，否则 \(p^n\) 里的一次采样就会变成磁盘上的转移。不可逆的事不要放进这个大动作空间，放回小的函数工具，并在转移前加人审。

## ⚠️ 常见坑

1. 觉得用了子进程就安全——子进程里的代码默认继承你的很多权限
2. 把代码工具当成万能工具——参数固定的事情用普通函数更稳
3. 失败不回灌 stderr——模型看不到为什么挂，就会原样再写一遍
4. 压缩成散文——没有「已确认 / 未完成」，下一步无法接着做
5. 子 Agent 传回全部检索原文——上下文隔离的好处被一次转交抵消

## 📝 小结

- 代码执行是另一种工具：模型写，程序在沙箱里跑，stdout/stderr 成为观察
- 子进程、超时、静态检查、权限是四层，少一层就有对应的洞
- 每一轮上下文只留「下一步做错会缺的那些」：角色、允许的工具、标记过的资料、任务状态、近期观察、用户原话
- 压缩结果要分成已确认事实和未完成步骤；子任务只交回结论
- 全课程到这里可以收束：01 的四件套，02 的可解析输出，03 的循环，04 的外部资料，05 的状态图，06 的协议和分工，07 的评测和人审，08 的第二种手和上下文取舍

## 💬 自学问答

**问：任务 4 既然能 `import os`，这个练习算不算教人怎么逃出沙箱？**
不算。它只打印操作系统名字，用来证明「没检查时子进程挡不住 import」。课文明确说权限还要另做。不要把这个脚本改去列目录或读文件。

**问：真要做一个能跑数据的代码工具，最低配置是什么？**
临时目录 + 超时 + 禁网 + 不把 API key 放进环境变量给子进程。做不到这四条，就不要给助理加代码工具，先用 03 篇那种白名单函数。

**问：上下文工程和 Prompt 工程是两件事吗？**
Prompt 工程偏「这句话怎么写」。上下文工程偏「这一轮把哪些材料放进去、哪些拿掉」。Agent 跑多步之后，后者更决定成败。

## 📝 小测验

先盖住答案。

1. 子进程超时成功返回了，是否说明这段代码没有读过磁盘？
2. 为什么压缩后的状态里要单独写「不要再做」？
3. 代码工具和 `calculator(expr)` 这种函数工具，什么时候选哪个？
4. 为什么多塞一段「也许有用」的资料，模型有时反而更不用那条真正相关的证据？

### 参考答案

1. 不能说明。超时只表示你不再等、或者进程被杀掉。它在被杀掉之前可能已经读过文件。读盘要靠权限，不靠超时。超时改的是环境转移，不是模型会不会写出读文件的代码。
2. 因为下一步的分布只条件在留下的 token 上。不写「不要再做」，重复搜索的概率不会自己下降。
3. 计算式、单位、参数范围能写进 Schema 的，用函数工具。动作空间小，转移是你写的。临时的、形状每次都变的变换，才用代码工具，并且把转移收进沙箱。
4. 一个注意力头里权重和为 1。新资料要参与同一次 softmax，相关证据分到的权重变小。再加上中间位置更容易被弱化，相关段落放在长文中间时，峰值可能根本不条件在它上面。
