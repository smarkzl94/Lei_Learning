# AI Agent 开发专题

> 前置：已完成 PyTorch 主线 00~05 章 + Transformer 专题（懂自注意力、会搭训练循环）。
> 目标：从"会训练模型"升级到"会让模型干活"——手写 Agent 循环 → 用框架 → 多智能体 → 上线。
> 这份笔记按「换一台电脑、旁边没有助手」来写。每篇有自测答案，`practice/` 里的脚本不需要 API key。

## 怎么学

1. 先看 [术语表](术语表.md)，不用背，后面当字典用。
2. 按 01 → 08 的顺序。一篇里先读知识点，再读「原理」（公式要能讲出每个符号是什么），盖住「参考答案」做小测验，最后跑对应脚本。
3. 脚本末尾出现「自检通过」才算这一篇的代码过关。一次只改文件顶部写的那一处。
4. 卡住时的顺序：该篇小结 → 自学问答 → 脚本打印 → 术语表。仍不懂就填进该篇「我的疑问」，不要同时改两个脚本。
5. 八个脚本都通过之后，再做 07 篇第 9 节的 10 个毕业任务。LangGraph、CrewAI、云端 API 都是这之后的选做。

## 🗺 课程地图

| 篇 | 主题 | 核心问题 | 配套实战 |
|---|---|---|---|
| 01 | 什么是 AI Agent | Agent 和聊天机器人差在哪？大脑/工具/记忆/规划四件套 | 无代码，做文末测验 |
| 02 | Prompt 工程与结构化输出 | 怎么让模型稳定输出能解析的 JSON？ | practice/agent01_json_output.py |
| 03 | 工具调用：Function Calling 与 ReAct | 模型怎么决定调哪个工具？真实的 tool_call_id | practice/agent02_react_loop.py |
| 04 | RAG 检索增强 | 模型不知道的事怎么现查？查不到怎么停？ | practice/agent03_mini_rag.py |
| 05 | 记忆与规划 | 长任务怎么压缩？状态图怎么断点续跑？ | practice/agent04_state_graph.py |
| 06 | 多智能体与 MCP | 什么时候才拆多个 Agent？工具协议长什么样？ | practice/agent05_pipeline.py、agent06_mini_mcp.py |
| 07 | 评测、安全与上线 | 答对了是否等于过程对？毕业项目怎么验收？ | practice/agent07_trace_eval.py |
| 08 | 代码执行与上下文工程 | 模型写的代码能跑到哪一步？这一轮上下文留什么？ | practice/agent08_code_sandbox.py |

每篇实战之前有一节「原理」。自学时这一节优先于口诀：

| 篇 | 要能讲出来的机制 |
|---|---|
| 01 | 每步做对的概率连乘 \(p^n\)；观察是测量，工具调用是控制量；循环里参数不变 |
| 02 | 生成是 \(p(y\mid x)\)；few-shot 主要稳定格式；约束解码是把非法续写的概率设为 0 |
| 03 | 工具名是上下文里的 token，不是函数表查找；观察写回去，下一步的分布才变 |
| 04 | 句向量是隐藏状态的平均，所以会稀释；BM25 让稀有词权重大、词频饱和；双编码器查询时没有逐词交互 |
| 05 | 下一步只条件在留下的 token 上；KV cache 是加速不是记忆；ReAct 是短视闭环 |
| 06 | 拆开是为了缩短条件；每一跳有传递损失 \(q\)；这一轮的工具清单决定动作支撑集 |
| 07 | 最终对错分配不到中间步；裁判分布有位置、长度、自偏好；指令和数据在同一条 token 流里 |
| 08 | 注意力权重和为 1；沙箱改的是环境转移，不是模型会写出什么 |

## 🛠 环境说明

- Python 3.11 及以上。练习只用标准库
- 配图若打不开：在本目录执行 `python assets/make_01_figures.py` 和 `python assets/make_02_07_figures.py`（需要 matplotlib）
- 真 API 是选做。接法在 02 篇第 8 节，Key 放环境变量
- LangGraph / CrewAI 也是选做。05、06 篇的必做练习不安装它们
