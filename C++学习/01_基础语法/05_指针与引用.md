## 📚 核心知识点

### 1. 指针基础

#### 声明与初始化
```cpp
int* p;           // 声明一个指向 int 的指针（未初始化，危险！）
int* p = nullptr; // 初始化为空指针（C++11 推荐）
int x = 10;
int* p = &x;      // p 指向 x
```

#### 解引用
```cpp
int x = 10;
int* p = &x;

std::cout << p;   // 输出 x 的地址
std::cout << *p;  // 输出 10（解引用）

*p = 20;          // 通过指针修改 x 的值
std::cout << x;   // 输出 20
```

### 2. 指针与数组
```cpp
int arr[] = {10, 20, 30, 40, 50};
int* p = arr;     // 数组名即首元素地址

// 指针算术
std::cout << *p;       // 10
std::cout << *(p+1);   // 20
std::cout << *(p+2);   // 30

// 等价写法
std::cout << p[0];     // 10
std::cout << p[1];     // 20
std::cout << p[2];     // 30

// 遍历
for (int i = 0; i < 5; ++i) {
    std::cout << *(p + i) << " ";
}
```

### 3. 常量指针 vs 指针常量
```cpp
int a = 10, b = 20;

// 指针常量：指针本身不能变，指向的内容可以变
int* const p1 = &a;
*p1 = 100;      // OK
// p1 = &b;     // 错误！p1 不能指向别处

// 常量指针：指向的内容不能变，指针本身可以变
const int* p2 = &a;
// *p2 = 100;   // 错误！不能修改指向的内容
p2 = &b;        // OK

// 指向常量的常量指针：都不能变
const int* const p3 = &a;
```

> **记忆口诀**：`const` 在 `*` 右边修饰指针，在 `*` 左边修饰指向的内容。

### 4. 引用
```cpp
int x = 10;
int& ref = x;     // ref 是 x 的引用（别名）

ref = 20;         // 等价于 x = 20
std::cout << x;   // 输出 20

// 引用必须初始化，且不能重新绑定
int y = 30;
// int& ref2;     // 错误！引用必须初始化
ref = y;          // 这是赋值，不是重新绑定！x 的值变为 30
```

### 5. 指针 vs 引用

| 特性 | 指针 | 引用 |
|------|------|------|
| 是否可为空 | 可以（nullptr） | 不可以 |
| 是否可以重新指向 | 可以 | 不可以（始终绑定同一对象） |
| 是否需要解引用 | 需要 `*` | 不需要 |
| 语法复杂度 | 较复杂 | 简洁 |
| 使用场景 | 动态内存、可选对象、多态 | 函数参数、运算符重载 |

### 6. 多级指针
```cpp
int x = 10;
int* p = &x;       // 一级指针
int** pp = &p;     // 二级指针
int*** ppp = &pp;  // 三级指针

std::cout << ***ppp;  // 输出 10
```

### 7. void* 指针
```cpp
// void* 可以指向任何类型，但不能直接解引用
int x = 10;
void* p = &x;

// 需要强制转换才能使用
int* ip = static_cast<int*>(p);
std::cout << *ip;  // 输出 10
```

## 💻 代码示例

```cpp
#include <iostream>

// 交换函数对比
void swap_by_pointer(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

void swap_by_reference(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

// 指针作为数组参数
void print_array(const int* arr, size_t size) {
    for (size_t i = 0; i < size; ++i) {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;
}

int main() {
    int x = 10, y = 20;
    
    // 指针交换
    swap_by_pointer(&x, &y);
    std::cout << x << ", " << y << std::endl;  // 20, 10
    
    // 引用交换（更简洁）
    swap_by_reference(x, y);
    std::cout << x << ", " << y << std::endl;  // 10, 20
    
    // 数组与指针
    int arr[] = {1, 2, 3, 4, 5};
    print_array(arr, 5);
    
    return 0;
}
```

## ❓ 常见问题

**Q: 引用和指针的本质区别是什么？**
A: 引用在底层实现上通常也是指针，但编译器限制了它的行为：必须初始化、不能重新绑定、不能为 null。引用是更安全的语法糖。

**Q: 什么时候用指针，什么时候用引用？**
A: 能用引用就用引用（更安全）；需要指向不同对象、可能为空、需要动态分配时用指针。

**Q: `int* p` 和 `int *p` 有区别吗？**
A: 没有区别，只是风格问题。C++ 风格推荐 `int* p`（强调类型是 "指向 int 的指针"），C 风格常用 `int *p`。
