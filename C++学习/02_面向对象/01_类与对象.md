## 📚 核心知识点

### 1. 类的定义
```cpp
class Student {
public:              // 公有成员：外部可访问
    // 成员函数（方法）
    void setName(const std::string& n);
    std::string getName() const;
    void printInfo() const;

private:             // 私有成员：仅类内部可访问
    // 成员变量（属性）
    std::string name;
    int age;
    double score;
};

// 成员函数实现
void Student::setName(const std::string& n) {
    name = n;
}

std::string Student::getName() const {
    return name;
}

void Student::printInfo() const {
    std::cout << "Name: " << name << ", Age: " << age << std::endl;
}
```

### 2. 对象的创建与使用
```cpp
// 栈上创建对象
Student stu1;
stu1.setName("Alice");   // 使用 . 访问成员

// 堆上创建对象
Student* stu2 = new Student();
stu2->setName("Bob");    // 使用 -> 访问成员
delete stu2;             // 必须手动释放

// C++11 统一初始化
Student stu3{"Charlie", 20, 85.5};
```

### 3. 访问控制

| 访问修饰符 | 类内部 | 子类 | 外部 |
|-----------|--------|------|------|
| `public` | ✓ | ✓ | ✓ |
| `protected` | ✓ | ✓ | ✗ |
| `private` | ✓ | ✗ | ✗ |

### 4. struct vs class
```cpp
// struct 默认 public
struct Point {
    double x;  // 默认 public
    double y;
};

// class 默认 private
class Point2 {
    double x;  // 默认 private
    double y;
};
```
> 本质相同，只是默认访问权限不同。通常用 `struct` 表示纯数据结构，用 `class` 表示有封装行为的抽象。

### 5. this 指针

**作用**：`this` 是一个隐式指针，指向**当前正在调用成员函数的对象本身**。每个非静态成员函数内部都有一个隐藏的 `this` 参数。

**什么时候必须用**：
- **成员变量和参数同名**时：区分 `this->name`（成员变量）和 `name`（参数）
- **返回当前对象**时：支持链式调用（如 `obj.setA(1).setB(2)`）
- **在成员函数内部需要把当前对象传给别人**时

```cpp
class Person {
public:
    void setName(const std::string& name) {
        this->name = name;  // this->name 是成员变量，name 是参数
    }
    
    Person* getThis() {
        return this;  // 返回当前对象的指针
    }
    
private:
    std::string name;
};
```

> 💡 记忆口诀：**"我是我"** → `this->name` 是对象的成员变量，`name` 只是函数参数。

### 6. 静态成员

**作用**：静态成员属于**类本身**，而不是某个具体的对象。所有对象共享**同一份**静态成员。

**常见用途**：
- **对象计数器**：统计创建了多少个实例
- **全局配置**：类的默认参数、版本号等
- **工具函数**：不需要对象状态就能完成的操作

**注意事项**：
- 静态成员函数**没有 `this` 指针**，不能访问非静态成员
- 静态成员变量**必须在类外初始化**

```cpp
class Counter {
public:
    Counter() {
        ++count;  // 每创建一个对象，计数增加
    }
    
    static int getCount() {  // 静态成员函数
        return count;
    }
    
private:
    static int count;  // 静态成员变量声明
};

int Counter::count = 0;  // 静态成员变量定义和初始化

// 使用
Counter c1, c2;
std::cout << Counter::getCount();  // 输出 2
```

> 💡 记忆口诀：**"大家共享"** → 不属于任何一个人，属于整个班级。

### 7. 常量成员函数

**作用**：在函数参数列表后加 `const`，表示该函数**承诺不修改对象的任何成员变量**。这是编译器层面的约束，一旦函数体内尝试修改成员就会编译报错。

**为什么重要**：
- **`const` 对象只能调用 `const` 成员函数**：如果不加 `const`，`const` 对象连 getter 都调不了
- **自文档化**：一眼就能看出这个函数是"只读"的
- **编译器帮你兜底**：防止在不该改的地方意外修改了状态

**`const` 放在后面的原因**：
这里的 `const` 修饰的不是返回值，而是**隐藏的 `this` 指针**。`double getArea() const` 相当于编译器把函数变成 `double getArea(const Rectangle* this)`，表示通过这个指针不能修改指向的对象。

```cpp
class Date {
public:
    int getYear() const {   // const 成员函数：不修改对象状态
        return year;
    }
    
    void setYear(int y) {   // 非 const：可以修改
        year = y;
    }
    
private:
    int year;
};

const Date d{2024};
d.getYear();   // OK：const 对象只能调用 const 成员函数
// d.setYear(2025);  // 错误！
```

> 💡 记忆口诀：**"只看不摸"** → 我保证进来啥样出去还啥样。

## 💻 代码示例

```cpp
#include <iostream>
#include <string>

class Rectangle {
public:
    // 构造函数
    Rectangle(double w, double h) : width(w), height(h) {}
    
    // 默认参数构造函数
    Rectangle() : Rectangle(1.0, 1.0) {}  // 委托构造函数（C++11）
    
    // 成员函数
    double getArea() const {
        return width * height;
    }
    
    double getPerimeter() const {
        return 2 * (width + height);
    }
    
    void setWidth(double w) {
        if (w > 0) width = w;
    }
    
    void setHeight(double h) {
        if (h > 0) height = h;
    }
    
private:
    double width;
    double height;
};

int main() {
    Rectangle rect{5.0, 3.0};
    std::cout << "Area: " << rect.getArea() << std::endl;
    std::cout << "Perimeter: " << rect.getPerimeter() << std::endl;
    
    return 0;
}
```

## ❓ 常见问题

**Q: 数据成员应该放在 public 还是 private？**
A: 遵循封装原则：数据成员放 private，通过 public 的 getter/setter 访问。这样可以在 setter 中加入合法性检查。

**Q: 什么时候用 struct，什么时候用 class？**
A: 没有强制规定，常见约定是：struct 用于简单的、只有数据的数据结构（POD）；class 用于有复杂行为、需要封装的抽象。

**Q: 为什么 `const` 放在成员函数参数列表的后面，而不是像 `const int` 那样放前面？**
A: 参数列表后面的 `const` 修饰的不是返回值类型，而是**隐藏的 `this` 指针**。`double getArea() const` 相当于编译器把它变成 `double getArea(const Rectangle* this)`，表示通过这个指针不能修改指向的对象。而 `const int` 中的 `const` 修饰的是 `int` 类型本身，两者语法位置不同但逻辑一致——都是表示"不可修改"。
