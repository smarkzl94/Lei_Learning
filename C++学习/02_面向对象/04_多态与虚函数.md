## 📚 核心知识点

### 1. 虚函数

```cpp
class Animal {
public:
    virtual void speak() {           // 虚函数
        std::cout << "Animal speaks" << std::endl;
    }
    
    virtual ~Animal() {}             // 虚析构函数（重要！）
};

class Dog : public Animal {
public:
    void speak() override {          // 重写虚函数
        std::cout << "Dog barks" << std::endl;
    }
};

class Cat : public Animal {
public:
    void speak() override {
        std::cout << "Cat meows" << std::endl;
    }
};

// 使用多态
void makeSound(Animal* animal) {
    animal->speak();  // 运行时根据实际对象类型调用对应函数
}

Animal* dog = new Dog();
Animal* cat = new Cat();

makeSound(dog);  // "Dog barks"
makeSound(cat);  // "Cat meows"

delete dog;
delete cat;
```

### 2. 纯虚函数与抽象类

```cpp
class Shape {
public:
    virtual double getArea() const = 0;   // 纯虚函数
    virtual double getPerimeter() const = 0;
    
    virtual ~Shape() = default;
    
    void printInfo() const {              // 非虚函数也可有实现
        std::cout << "Area: " << getArea() << std::endl;
    }
};

// Shape 是抽象类，不能实例化
// Shape s;  // 错误！

class Rectangle : public Shape {
public:
    double getArea() const override { return width * height; }
    double getPerimeter() const override { return 2 * (width + height); }
private:
    double width, height;
};
```

### 3. override 和 final（C++11）

#### 3.1 `override` — 编译器帮我把关

`override` 是 C++11 引入的关键字，作用是**显式告诉编译器：这个函数是要重写（覆盖）基类的虚函数**。如果签名不匹配，编译器会直接报错，而不是静默变成"名称隐藏"。

**为什么需要 `override`？**

没有 `override` 时，一个常见的坑：

```cpp
class Base {
public:
    virtual void foo(int x) const {}
};

class Derived : public Base {
public:
    void foo(int x) {}  // ❌ 少写了 const！但编译器不报错
};
```

<br />

你以为重写了 `foo`，实际上因为 `const` 不匹配，这是**两个不同的函数**。`Derived` 对象调用 `foo` 时走的是自己的版本，但通过基类指针调用时还是走的 `Base::foo`——**多态没生效**，而且编译器不会提醒你。

加上 `override`：

```cpp
class Derived : public Base {
public:
    void foo(int x) override {}  // ❌ 编译错误！Base::foo 是 const 的，签名不匹配
};
```

编译器立刻报错：**"marked override but does not override"**，强迫你修正。

**使用方式**：

```cpp
class Animal {
public:
    virtual void speak() const {}
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void speak() const override {}   // ✅ 显式声明：我在重写基类的虚函数
};
```

**规则**：只有虚函数重写才用 `override`，普通函数、名称隐藏、非虚函数都不能用。

#### 3.2 `final` — 到此为止，不许再重写

`final` 也是 C++11 引入的，作用与 `override` 相反：**禁止子类进一步重写虚函数，或禁止类被继承**。

**用法一：禁止虚函数被进一步重写**

```cpp
class Base {
public:
    virtual void foo();
    virtual void bar();
};

class Derived : public Base {
public:
    void foo() override final;  // 我重写了，但我的子类不许再重写
};

class MoreDerived : public Derived {
public:
    // void foo() override;  // ❌ 编译错误！foo 被 final 了
};
```

**用法二：禁止类被继承**

```cpp
class FinalClass final {};     // 禁止继承
// class Sub : public FinalClass {};  // ❌ 编译错误！
```

#### 3.3 `override` vs `final` 对比

| 关键字        | 作用         | 使用位置          | 核心含义           |
| ---------- | ---------- | ------------- | -------------- |
| `override` | 确认重写基类虚函数  | 派生类成员函数       | "请编译器检查我确实在重写" |
| `final`    | 禁止进一步重写/继承 | 派生类成员函数 / 类声明 | "到此为止，不许再动"    |

**一句话总结**：

* `override` = 请编译器当我的保镖，确认我写的这个函数确实是在重写基类的虚函数

* `final` = 画一条红线，我的子类不许跨越

### 4. 虚函数表（vtable）原理

```
+-----------+      +------------------+
| Animal    |      | Animal vtable    |
| - vptr    |----->| [0] Animal::speak|
+-----------+      | [1] ~Animal      |
                     +------------------+

+-----------+      +------------------+
| Dog       |      | Dog vtable       |
| - vptr    |----->| [0] Dog::speak   |
+-----------+      | [1] ~Dog         |
                     +------------------+
```

* 每个含虚函数的类有一个虚函数表

* 每个对象有一个虚指针（vptr）指向该表

* 运行时通过 vptr 查找实际调用的函数

### 5. 协变返回类型

```cpp
class Animal {
public:
    virtual Animal* clone() const {
        return new Animal(*this);
    }
};

class Dog : public Animal {
public:
    Dog* clone() const override {  // 返回类型可以是派生类指针
        return new Dog(*this);
    }
};
```

## 💻 代码示例

```cpp
#include <iostream>
#include <vector>
#include <memory>

class Shape {
public:
    virtual double getArea() const = 0;
    virtual ~Shape() = default;
};

class Circle : public Shape {
public:
    Circle(double r) : radius(r) {}
    double getArea() const override {
        return 3.14159 * radius * radius;
    }
private:
    double radius;
};

class Rectangle : public Shape {
public:
    Rectangle(double w, double h) : width(w), height(h) {}
    double getArea() const override {
        return width * height;
    }
private:
    double width, height;
};

int main() {
    // 使用智能指针管理多态对象
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Circle>(5));
    shapes.push_back(std::make_unique<Rectangle>(4, 6));
    
    double total = 0;
    for (const auto& shape : shapes) {
        total += shape->getArea();
    }
    std::cout << "Total area: " << total << std::endl;
    
    return 0;
}
```

## ❓ 常见问题

**Q: 虚函数有什么性能开销？**
A: 虚函数通过虚函数表间接调用，比普通函数多一次间接寻址。对性能敏感的内层循环代码应避免虚函数。

**Q: 构造函数可以是虚函数吗？**
A: 不可以。构造时对象类型还未完全确定，vptr 还未初始化完成。

**Q: 纯虚函数可以有实现吗？**
A: 可以！纯虚函数 `= 0` 只表示类是抽象的，但仍可提供默认实现，派生类可以用 `Base::foo()` 调用。
