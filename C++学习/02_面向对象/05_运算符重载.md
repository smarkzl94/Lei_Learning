## 📚 核心知识点

### 1. 基本概念

#### 1.1 成员函数 vs 非成员函数重载

```cpp
class Complex {
public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    
    // 成员函数形式重载 +
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }
    
    // 重载 <<（友元函数）
    friend std::ostream& operator<<(std::ostream& os, const Complex& c);
    
private:
    double real, imag;
};

std::ostream& operator<<(std::ostream& os, const Complex& c) {
    os << c.real << " + " << c.imag << "i";
    return os;
}

// 使用
Complex a(1, 2);
Complex b(3, 4);
Complex c = a + b;       // 等价于 a.operator+(b)
std::cout << c << std::endl;  // 4 + 6i
```

#### 1.2 友元函数详解

**友元函数（Friend Function）** 是 C++ 中一种特殊的机制，它**打破了类的封装边界**——允许一个外部函数访问类的 `private` 和 `protected` 成员。

**为什么需要友元？**

来看 `<<` 运算符重载这个经典场景：

```cpp
class Complex {
private:
    double real, imag;
public:
    Complex(double r, double i) : real(r), imag(i) {}
    
    // 尝试作为成员函数重载 <<
    std::ostream& operator<<(std::ostream& os) {
        os << real << " + " << imag << "i";
        return os;
    }
};

Complex c(3, 4);
c << std::cout;        // ❌ 反直觉！变成 c.operator<<(std::cout)
// 我们想要的是：std::cout << c;
```

**问题**：成员函数的左操作数固定是 `this`（即 `Complex` 对象），所以调用变成 `c << cout`，而不是 `cout << c`。

**解决**：把 `operator<<` 声明为**友元函数**（非成员函数），这样左操作数可以是 `std::ostream`：

```cpp
class Complex {
private:
    double real, imag;
public:
    Complex(double r, double i) : real(r), imag(i) {}
    
    // 友元声明：允许这个外部函数访问 private 成员
    friend std::ostream& operator<<(std::ostream& os, const Complex& c);
};

// 定义在类外部（不是成员函数！）
std::ostream& operator<<(std::ostream& os, const Complex& c) {
    os << c.real << " + " << c.imag << "i";  // ✅ 可以访问 private 的 real, imag
    return os;
}

// 现在可以像内置类型一样用了
std::cout << c << std::endl;   // ✅ "3 + 4i"
```

**友元函数的核心特点**：

| 特点           | 说明                                                   |
| ------------ | ---------------------------------------------------- |
| **不是成员函数**   | 友元函数定义在类外部，没有 `this` 指针                              |
| **可以访问私有成员** | 这是友元的唯一目的——突破封装                                      |
| **声明在类内部**   | 用 `friend` 关键字声明，告诉编译器"我信任这个函数"                      |
| **不受访问控制限制** | `friend` 声明放在 `public`、`private` 或 `protected` 里效果一样 |

**友元类**：除了友元函数，还可以把整个类声明为友元：

```cpp
class Engine {
private:
    int horsepower;
public:
    friend class Car;  // Car 可以访问 Engine 的所有私有成员
    
    Engine(int hp) : horsepower(hp) {}
};

class Car {
public:
    void showEngine(const Engine& e) {
        std::cout << "HP: " << e.horsepower << std::endl;  // ✅ 可以访问
    }
};
```

**实际使用频率**：

> **"友元不是敌人，但不要滥用。"**

* **高频场景**：`operator<<` 和 `operator>>` 重载（几乎无可替代）

* **中频场景**：数学类（Complex、Vector、Matrix）的二元运算符，需要支持 `5 + obj` 这种左操作数为内置类型的情况

* **低频场景**：单元测试、某些设计模式

现代 C++ 的趋势是**减少友元使用**——更好的封装设计、公共 getter、以及 C++20 的 `<=>` 三路比较运算符，都在减少友元的必要性。建议：学到 `<<` 重载就够了，其他场景遇到再说，不必刻意追求。

### 2. 重载规则

| 运算符                | 建议形式    | 说明       |
| ------------------ | ------- | -------- |
| `=` `[]` `()` `->` | 必须是成员   | 语法要求     |
| `+` `-` `*` `/`    | 成员或非成员  | 二元运算符    |
| `<<` `>>`          | 非成员（友元） | 左操作数是流对象 |
| `++` `--`          | 成员      | 区分前置/后置  |
| `==` `!=` `<`      | 成员或非成员  | 通常一起重载   |

### 3. 自增运算符重载

```cpp
class Counter {
public:
    // 前置++
    Counter& operator++() {
        ++value;
        return *this;
    }
    
    // 后置++（int 是区分标志）
    Counter operator++(int) {
        Counter temp(*this);
        ++value;
        return temp;
    }
    
private:
    int value = 0;
};
```

### 4. 下标运算符重载

```cpp
class Array {
public:
    int& operator[](size_t index) {
        if (index >= size) throw std::out_of_range("Index out of range");
        return data[index];
    }
    
    const int& operator[](size_t index) const {
        if (index >= size) throw std::out_of_range("Index out of range");
        return data[index];
    }
    
private:
    int* data;
    size_t size;
};
```

### 5. 函数调用运算符

```cpp
class MultiplyBy {
public:
    explicit MultiplyBy(int factor) : factor(factor) {}
    
    int operator()(int value) const {
        return value * factor;
    }
    
private:
    int factor;
};

// 使用
MultiplyBy triple(3);
int result = triple(5);  // 15
```

> 这种对象称为 "函数对象" 或 "仿函数"（functor），在 STL 中广泛使用。

### 6. 不能重载的运算符

```cpp
::    // 作用域解析
.*    // 成员指针访问
.     // 成员访问
?:    // 三目条件
sizeof
typeid
```

## 💻 代码示例

```cpp
#include <iostream>
#include <cmath>

class Vector2D {
public:
    Vector2D(double x = 0, double y = 0) : x(x), y(y) {}
    
    // 算术运算符
    Vector2D operator+(const Vector2D& other) const {
        return Vector2D(x + other.x, y + other.y);
    }
    
    Vector2D operator-(const Vector2D& other) const {
        return Vector2D(x - other.x, y - other.y);
    }
    
    Vector2D operator*(double scalar) const {
        return Vector2D(x * scalar, y * scalar);
    }
    
    // 复合赋值
    Vector2D& operator+=(const Vector2D& other) {
        x += other.x;
        y += other.y;
        return *this;
    }
    
    // 比较
    bool operator==(const Vector2D& other) const {
        return x == other.x && y == other.y;
    }
    
    bool operator!=(const Vector2D& other) const {
        return !(*this == other);
    }
    
    // 友元：允许 double * Vector2D
    friend Vector2D operator*(double scalar, const Vector2D& v) {
        return v * scalar;
    }
    
    friend std::ostream& operator<<(std::ostream& os, const Vector2D& v) {
        os << "(" << v.x << ", " << v.y << ")";
        return os;
    }
    
    double magnitude() const {
        return std::sqrt(x * x + y * y);
    }
    
private:
    double x, y;
};

int main() {
    Vector2D a(1, 2);
    Vector2D b(3, 4);
    
    Vector2D c = a + b;
    Vector2D d = 2.0 * a;  // 友元函数
    
    std::cout << "a = " << a << std::endl;
    std::cout << "b = " << b << std::endl;
    std::cout << "a + b = " << c << std::endl;
    std::cout << "2 * a = " << d << std::endl;
    
    return 0;
}
```

## ❓ 常见问题

**Q: 运算符重载应该返回引用还是值？**
A: 赋值运算符和复合赋值运算符返回引用（支持连等）；算术运算符返回值（创建新对象）。

**Q: 对称的二元运算符应该用成员还是非成员？**
A: 建议用非成员（或友元），这样可以支持 `2 + obj` 和 `obj + 2`。

**Q: 什么时候不应该重载运算符？**
A: 当运算符的语义不直观时。例如用 `+` 做字符串拼接是直观的，但用 `*` 做字符串重复就不太直观。
