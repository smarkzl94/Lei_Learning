## 📚 核心知识点

### 1. 值类别

```cpp
int x = 10;

// 左值（lvalue）：有名字，可取地址
x;              // 左值
int& getX() { return x; }
getX();         // 左值

// 右值（rvalue）：临时值，不能取地址
10;             // 纯右值
int getVal() { return x; }
getVal();       // 纯右值

// 将亡值（xvalue）：即将被移动的对象
std::move(x);   // 将亡值
```

### 2. 左值引用与右值引用
```cpp
int x = 10;

int& lref = x;          // 左值引用（绑定左值）
// int& lref2 = 10;     // 错误！不能绑定右值

const int& clref = 10;  // const 左值引用可以绑定右值

int&& rref = 10;        // 右值引用（绑定右值）
int&& rref2 = x;        // 错误！不能绑定左值
int&& rref3 = std::move(x);  // OK，显式转换为右值
```

### 3. 移动构造函数
```cpp
class String {
public:
    // 拷贝构造
    String(const String& other) 
        : data(new char[strlen(other.data) + 1]) {
        strcpy(data, other.data);
    }
    
    // 移动构造（右值引用参数）
    String(String&& other) noexcept 
        : data(other.data) {      // 直接接管指针
        other.data = nullptr;     // 将源对象置空
    }
    
    // 移动赋值
    String& operator=(String&& other) noexcept {
        if (this != &other) {
            delete[] data;        // 释放自己的资源
            data = other.data;    // 接管资源
            other.data = nullptr; // 置空源对象
        }
        return *this;
    }
    
private:
    char* data;
};

// 触发移动
String createString() {
    String s("Hello");
    return s;  // 返回值优化（RVO）或移动构造
}

String s1 = createString();  // 移动构造
String s2("World");
s1 = std::move(s2);          // 移动赋值，s2 变为空
```

### 4. std::move
```cpp
// std::move 本质上是一个类型转换
// static_cast<T&&>(arg)

template <typename T>
typename std::remove_reference<T>::type&& move(T&& arg) noexcept {
    return static_cast<typename std::remove_reference<T>::type&&>(arg);
}

// 使用
int x = 10;
int&& r = std::move(x);  // x 仍然是有效的，但值不确定
// 使用 std::move 后，不要再使用原变量！
```

> **注意**：`std::move` 不移动任何数据，只是将左值转换为右值引用，让编译器选择移动构造函数。

### 5. 完美转发
```cpp
// 问题：模板参数推导会丢失引用信息
template <typename T>
void wrapper(T arg) {       // 按值传递，会拷贝
    foo(arg);
}

// 解决方案：万能引用 + std::forward
template <typename T>
void perfect_wrapper(T&& arg) {  // 万能引用
    foo(std::forward<T>(arg));   // 完美转发：保留原值类别
}

// 规则：
// T&& + 类型推导 = 万能引用（可绑定左值或右值）
// 如果传入左值：T = int&，T&& = int&（引用折叠）
// 如果传入右值：T = int，T&& = int&&

// 使用
int x = 10;
perfect_wrapper(x);           // T = int&，arg 是左值引用
perfect_wrapper(20);          // T = int，arg 是右值引用
```

### 6. 引用折叠
```cpp
// 推导后的引用折叠规则：
T& &   → T&    // 左值引用 + 左值引用 = 左值引用
T& &&  → T&    // 左值引用 + 右值引用 = 左值引用
T&& &  → T&    // 右值引用 + 左值引用 = 左值引用
T&& && → T&&   // 右值引用 + 右值引用 = 右值引用

// 总结：只要有左值引用，结果就是左值引用
```

## 💻 代码示例

```cpp
#include <iostream>
#include <vector>
#include <string>

class Resource {
public:
    Resource() { std::cout << "Default construct" << std::endl; }
    Resource(const Resource&) { std::cout << "Copy construct" << std::endl; }
    Resource(Resource&&) noexcept { std::cout << "Move construct" << std::endl; }
};

// 万能引用 + 完美转发
template <typename T>
void process(T&& x) {
    // std::forward<T>(x) 保持原值类别
    some_function(std::forward<T>(x));
}

// 移动语义的实际应用
std::vector<std::string> createHugeVector() {
    std::vector<std::string> result;
    // 填充大量数据...
    result.push_back(std::string(1000, 'x'));
    return result;  // 移动语义避免拷贝
}

int main() {
    std::vector<std::string> v1;
    v1.push_back("Hello");  // 从 const char* 构造
    
    std::string str = "World";
    v1.push_back(std::move(str));  // 移动 str，str 变为空
    
    std::vector<std::string> v2 = std::move(v1);  // 移动整个 vector
    // v1 现在为空 vector
    
    return 0;
}
```

## ❓ 常见问题

**Q: 移动后原对象还能用吗？**
A: 处于 "有效但未指定状态"，可以重新赋值或销毁，但不应依赖其值。

**Q: 为什么移动构造要加 noexcept？**
A: **`std::vector` 等容器在扩容时，如果移动构造不是 `noexcept`，宁可慢 1000 倍的拷贝也不敢用移动**——因为移动操作中途抛异常会导致数据丢失（源对象已被破坏，新对象也没建好）。只有 `noexcept` 承诺不抛异常，标准库才放心使用移动。

```cpp
// ✅ 有 noexcept：vector 扩容时移动，快
class Data {
public:
    Data(Data&& other) noexcept : buf(other.buf) {
        other.buf = nullptr;
    }
};

// ❌ 没 noexcept：vector 扩容时拷贝，慢
class DataSlow {
public:
    DataSlow(DataSlow&& other) : buf(other.buf) {  // 隐式 noexcept(false)
        other.buf = nullptr;
    }
};
```
A: `std::vector` 等容器在增长时，如果移动构造是 noexcept 才用移动，否则用拷贝（为了异常安全）。

**Q: 万能引用和右值引用的区别？**
A: `T&&` 在发生类型推导时是万能引用；在具体的类型（如 `int&&`）时是右值引用。
