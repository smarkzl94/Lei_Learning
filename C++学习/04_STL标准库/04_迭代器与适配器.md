## 📚 核心知识点

### 1. 迭代器分类

| 迭代器类型 | 支持操作 | 示例容器 |
|-----------|----------|----------|
| 输入迭代器 | `++`、`*`、 `==` | istream_iterator |
| 输出迭代器 | `++`、`*` | ostream_iterator |
| 前向迭代器 | 输入 + 可多次遍历 | forward_list、unordered_* |
| 双向迭代器 | 前向 + `--` | list、set、map |
| 随机访问迭代器 | 双向 + `+` `-` `[]` `<` | vector、deque、array |
| 连续迭代器（C++17） | 随机 + 内存连续 | vector、array、string |

### 2. 迭代器适配器

#### 反向迭代器
```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

// 反向遍历
for (auto it = v.rbegin(); it != v.rend(); ++it) {
    std::cout << *it << " ";  // 5 4 3 2 1
}

// 注意：reverse_iterator 的 base() 指向不同位置
auto rit = v.rbegin();       // 指向 5
auto it = rit.base();        // 指向 5 之后（即 4 之前）
```

#### 插入迭代器
```cpp
#include <iterator>

std::vector<int> v = {1, 2, 3};
std::vector<int> src = {4, 5, 6};

// back_insert_iterator：在尾部插入
std::copy(src.begin(), src.end(), std::back_inserter(v));
// v: 1, 2, 3, 4, 5, 6

// front_insert_iterator：在头部插入（仅支持 front 操作）
std::list<int> lst = {3, 4, 5};
std::copy(src.begin(), src.end(), std::front_inserter(lst));
// lst: 6, 5, 4, 3, 4, 5

// insert_iterator：在指定位置插入
auto it = v.begin() + 2;
std::copy(src.begin(), src.end(), std::inserter(v, it));
```

#### 流迭代器
```cpp
#include <iterator>
#include <sstream>

// istream_iterator：从输入流读取
std::istringstream iss("1 2 3 4 5");
std::vector<int> nums(
    std::istream_iterator<int>(iss),
    std::istream_iterator<int>()  // 结束迭代器
);

// ostream_iterator：向输出流写入
std::copy(nums.begin(), nums.end(),
    std::ostream_iterator<int>(std::cout, " "));
```

### 3. 迭代器辅助函数
```cpp
#include <iterator>

std::advance(it, n);        // 迭代器前进 n 步
std::distance(it1, it2);    // 两个迭代器之间的距离
std::next(it);              // 返回下一个迭代器（C++11）
std::prev(it);              // 返回上一个迭代器（C++11）
std::begin(container);      // 返回 begin 迭代器（C++11）
std::end(container);        // 返回 end 迭代器（C++11）
```

### 4. 自定义迭代器（简介）
```cpp
// 最简单的迭代器：指针就是一种随机访问迭代器
int arr[] = {1, 2, 3, 4, 5};
int* begin = arr;
int* end = arr + 5;
std::sort(begin, end);
```

## 💻 代码示例

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <algorithm>
#include <iterator>
#include <sstream>

int main() {
    // 反向迭代器
    std::vector<int> v = {1, 2, 3, 4, 5};
    std::cout << "Reverse: ";
    for (auto it = v.rbegin(); it != v.rend(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;
    
    // 插入迭代器
    std::vector<int> a = {1, 2, 3};
    std::vector<int> b = {4, 5, 6};
    std::copy(b.begin(), b.end(), std::back_inserter(a));
    
    // 流迭代器
    std::string data = "10 20 30 40 50";
    std::istringstream iss(data);
    std::vector<int> nums(
        std::istream_iterator<int>(iss),
        std::istream_iterator<int>()
    );
    
    std::cout << "Numbers: ";
    std::copy(nums.begin(), nums.end(),
        std::ostream_iterator<int>(std::cout, " "));
    
    return 0;
}
```

## ❓ 常见问题

**Q: `vector` 的迭代器在什么情况下会失效？**
A: 插入/删除可能导致重新分配时所有迭代器失效；插入/删除位置之后的迭代器失效。

**Q: 为什么 `ostream_iterator` 需要分隔符参数？**
A: 每次写入后自动输出分隔符，方便生成逗号分隔值（CSV）等格式。
