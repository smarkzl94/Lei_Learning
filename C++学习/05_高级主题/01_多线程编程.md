## 📚 核心知识点

### 1. 创建线程
```cpp
#include <thread>

void func(int id) {
    std::cout << "Thread " << id << std::endl;
}

int main() {
    // 用函数创建线程
    std::thread t1(func, 1);
    
    // 用 Lambda 创建线程
    std::thread t2([](int id) {
        std::cout << "Thread " << id << std::endl;
    }, 2);
    
    // 用成员函数
    class Worker {
    public:
        void run(int id) { /* ... */ }
    };
    Worker w;
    std::thread t3(&Worker::run, &w, 3);
    
    // 等待线程结束
    t1.join();   // 阻塞等待
    t2.join();
    t3.join();
    
    // 或分离线程（独立运行）
    // t1.detach();
    
    return 0;
}
```

### 2. 互斥锁
```cpp
#include <mutex>

std::mutex mtx;
int shared_data = 0;

void increment() {
    // 方式 1：手动 lock/unlock（不推荐，容易忘记 unlock）
    mtx.lock();
    ++shared_data;
    mtx.unlock();
    
    // 方式 2：lock_guard（RAII，推荐）
    {
        std::lock_guard<std::mutex> lock(mtx);
        ++shared_data;
    }  // 自动 unlock
    
    // 方式 3：unique_lock（更灵活）
    {
        std::unique_lock<std::mutex> lock(mtx);
        ++shared_data;
        lock.unlock();  // 可以提前解锁
    }
}
```

### 3. 条件变量
```cpp
#include <condition_variable>

std::mutex mtx;
std::condition_variable cv;
bool ready = false;

// 等待线程
void wait_for_signal() {
    std::unique_lock<std::mutex> lock(mtx);
    cv.wait(lock, [] { return ready; });  // 条件等待，避免虚假唤醒
    // 收到信号，继续执行
    std::cout << "Got signal!" << std::endl;
}

// 通知线程
void send_signal() {
    {
        std::lock_guard<std::mutex> lock(mtx);
        ready = true;
    }
    cv.notify_one();  // 通知一个等待线程
    // cv.notify_all(); // 通知所有等待线程
}
```

### 4. 原子操作
```cpp
#include <atomic>

std::atomic<int> counter(0);

void increment() {
    // 以下操作是原子的，无需锁
    ++counter;           // 原子自增
    counter.fetch_add(1); // 等价
    counter += 1;        // 等价
}

// 原子标志（用于简单同步）
std::atomic<bool> ready(false);

// 内存序
std::atomic<int> data(0);
data.store(42, std::memory_order_relaxed);
int value = data.load(std::memory_order_acquire);
```

### 5. 异步编程
```cpp
#include <future>

// async 异步执行
int compute(int x) {
    std::this_thread::sleep_for(std::chrono::seconds(1));
    return x * x;
}

int main() {
    // 异步启动
    std::future<int> result = std::async(std::launch::async, compute, 5);
    
    // 做其他事情...
    
    // 获取结果（阻塞等待）
    int value = result.get();
    std::cout << "Result: " << value << std::endl;
    
    // promise
    std::promise<int> prom;
    std::future<int> fut = prom.get_future();
    
    std::thread t([&prom]() {
        prom.set_value(42);  // 设置值
    });
    
    std::cout << fut.get() << std::endl;  // 42
    t.join();
    
    return 0;
}
```

## 💻 代码示例

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <queue>

// 线程安全的队列
template <typename T>
class ThreadSafeQueue {
public:
    void push(T value) {
        {
            std::lock_guard<std::mutex> lock(mtx);
            queue.push(std::move(value));
        }
        cv.notify_one();
    }
    
    T pop() {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, [this] { return !queue.empty(); });
        T value = std::move(queue.front());
        queue.pop();
        return value;
    }
    
private:
    std::queue<T> queue;
    std::mutex mtx;
    std::condition_variable cv;
};

int main() {
    ThreadSafeQueue<int> q;
    
    std::thread producer([&q]() {
        for (int i = 0; i < 10; ++i) {
            q.push(i);
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
        }
    });
    
    std::thread consumer([&q]() {
        for (int i = 0; i < 10; ++i) {
            int value = q.pop();
            std::cout << "Consumed: " << value << std::endl;
        }
    });
    
    producer.join();
    consumer.join();
    
    return 0;
}
```

## ❓ 常见问题

**Q: `join` 和 `detach` 的区别？**
A: `join` 阻塞等待线程结束；`detach` 让线程独立运行，主线程不等待。必须在析构前选择其一。

**Q: 为什么需要条件变量而不是轮询？**
A: 条件变量让线程阻塞等待，不消耗 CPU；轮询会浪费 CPU 资源。

**Q: `std::async` 的 `launch::deferred` 和 `launch::async` 区别？**
A: `async` 立即在新线程执行；`deferred` 延迟到 `get()` 时在当前线程执行。
