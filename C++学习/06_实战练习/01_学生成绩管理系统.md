# 01 - 学生成绩管理系统

## 🎯 项目目标
综合运用 C++ 面向对象知识，实现一个命令行版学生成绩管理系统。

---

## 📋 需求分析

### 功能需求
1. 添加学生（姓名、学号、多科成绩）
2. 删除学生
3. 查询学生（按学号或姓名）
4. 显示所有学生
5. 按总分排序
6. 统计信息（平均分、最高分、最低分）
7. 数据持久化（保存到文件/从文件加载）

### 类设计
```
Student
├── id: string
├── name: string
├── scores: map<string, int>  // 科目 -> 成绩
├── getTotalScore(): int
├── getAverageScore(): double
└── printInfo(): void

GradeManager
├── students: vector<Student>
├── addStudent(Student): void
├── removeStudent(string id): bool
├── findStudent(string id): Student*
├── sortByTotalScore(): void
├── saveToFile(string filename): void
└── loadFromFile(string filename): void
```

## 📝 参考实现框架

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>
#include <algorithm>
#include <fstream>

class Student {
public:
    Student(const std::string& id, const std::string& name)
        : id(id), name(name) {}
    
    void addScore(const std::string& subject, int score) {
        scores[subject] = score;
    }
    
    int getTotalScore() const {
        int total = 0;
        for (const auto& [subject, score] : scores) {
            total += score;
        }
        return total;
    }
    
    void printInfo() const {
        std::cout << "ID: " << id << ", Name: " << name << std::endl;
        for (const auto& [subject, score] : scores) {
            std::cout << "  " << subject << ": " << score << std::endl;
        }
        std::cout << "  Total: " << getTotalScore() << std::endl;
    }
    
    // Getters
    std::string getId() const { return id; }
    std::string getName() const { return name; }
    
private:
    std::string id;
    std::string name;
    std::map<std::string, int> scores;
};

class GradeManager {
public:
    void addStudent(const Student& student) {
        students.push_back(student);
    }
    
    bool removeStudent(const std::string& id) {
        auto it = std::find_if(students.begin(), students.end(),
            [&id](const Student& s) { return s.getId() == id; });
        if (it != students.end()) {
            students.erase(it);
            return true;
        }
        return false;
    }
    
    Student* findStudent(const std::string& id) {
        auto it = std::find_if(students.begin(), students.end(),
            [&id](const Student& s) { return s.getId() == id; });
        if (it != students.end()) {
            return &(*it);
        }
        return nullptr;
    }
    
    void sortByTotalScore() {
        std::sort(students.begin(), students.end(),
            [](const Student& a, const Student& b) {
                return a.getTotalScore() > b.getTotalScore();
            });
    }
    
    void printAll() const {
        for (const auto& student : students) {
            student.printInfo();
            std::cout << std::endl;
        }
    }
    
private:
    std::vector<Student> students;
};

int main() {
    GradeManager manager;
    
    // 添加学生
    Student s1("1001", "Alice");
    s1.addScore("Math", 85);
    s1.addScore("English", 90);
    manager.addStudent(s1);
    
    Student s2("1002", "Bob");
    s2.addScore("Math", 92);
    s2.addScore("English", 78);
    manager.addStudent(s2);
    
    // 排序并显示
    manager.sortByTotalScore();
    manager.printAll();
    
    return 0;
}
```
