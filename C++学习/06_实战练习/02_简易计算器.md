# 02 - 简易计算器

## 🎯 项目目标
实现一个支持四则运算和括号的命令行计算器。

---

## 📋 需求分析

### 功能需求
1. 支持 `+` `-` `*` `/` 四则运算
2. 支持括号 `(` `)`
3. 支持浮点数
4. 支持一元负号（如 `-5 + 3`）
5. 有基本的错误处理（除零、非法表达式）

### 实现思路
```
表达式求值的两种方法：
1. 中缀转后缀（Shunting Yard 算法）+ 后缀求值
2. 递归下降解析

推荐方法 1：
中缀: 3 + 4 * 2 / ( 1 - 5 )
后缀: 3 4 2 * 1 5 - / +
```

    Calculator calc;
