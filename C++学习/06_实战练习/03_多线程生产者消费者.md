# 03 - 多线程生产者消费者

## 🎯 项目目标
使用 C++11 线程库实现经典的生产者-消费者模型。

---

## 📋 需求分析

### 功能需求
1. 一个或多个生产者线程生成数据
2. 一个或多个消费者线程处理数据
3. 使用有界缓冲区作为共享资源
4. 缓冲区满时生产者等待
5. 缓冲区空时消费者等待
6. 线程安全，无数据竞争

### 核心组件
```
BoundedBuffer<T>
├── buffer: queue<T>
├── capacity: size_t
├── mutex: mutex
├── not_full: condition_variable
├── not_empty: condition_variable
├── produce(T): void
└── consume(): T
```

---

## 🚀 进阶挑战

### 基础版
- 单生产者 + 单消费者
- 固定大小缓冲区

### 进阶版
- 多生产者 + 多消费者
- 可配置缓冲区大小
- 统计生产/消费数量

### 高级版
- 使用无锁队列（lock-free）
- 支持优雅关闭（处理完缓冲区再退出）
- 添加性能统计（吞吐量、延迟）

## 📝 参考实现框架

```cpp
#include <iostream>
#include <queue>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <chrono>

template <typename T>
class BoundedBuffer {
public:
    explicit BoundedBuffer(size_t capacity) : capacity(capacity) {}
    
    void produce(T item) {
        std::unique_lock<std::mutex> lock(mtx);
        not_full.wait(lock, [this] { return buffer.size() < capacity; });
        
        buffer.push(std::move(item));
        std::cout << "Produced, buffer size: " << buffer.size() << std::endl;
        
        lock.unlock();
        not_empty.notify_one();
    }
    
    T consume() {
        std::unique_lock<std::mutex> lock(mtx);
        not_empty.wait(lock, [this] { return !buffer.empty(); });
        
        T item = std::move(buffer.front());
        buffer.pop();
        std::cout << "Consumed, buffer size: " << buffer.size() << std::endl;
        
        lock.unlock();
        not_full.notify_one();
        
        return item;
    }
    
private:
    std::queue<T> buffer;
    size_t capacity;
    std::mutex mtx;
    std::condition_variable not_full;
    std::condition_variable not_empty;
};

int main() {
    BoundedBuffer<int> buffer(5);
    
    std::thread producer([&buffer]() {
        for (int i = 0; i < 10; ++i) {
            buffer.produce(i);
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
        }
    });
    
    std::thread consumer([&buffer]() {
        for (int i = 0; i < 10; ++i) {
            int item = buffer.consume();
            std::this_thread::sleep_for(std::chrono::milliseconds(150));
        }
    });
    
    producer.join();
    consumer.join();
    
    return 0;
}
```
