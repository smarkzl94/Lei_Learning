# C++ 系统性学习计划

> **目标**：从零开始系统掌握 C++ 编程，达到能够熟练进行系统级开发、算法实现和 ROS 节点开发的水准。
>
> **学习理念**：逐个知识点扎实推进，理解一个再进入下一个，不追求速度。
> **适用人群**：编程零基础或有一定其他语言基础想转 C++

---

## 📚 学习路径

```
01 基础语法 ──→ 02 面向对象 ──→ 03 现代 C++
(变量/函数/   (类/继承/     (智能指针/
 指针/数组)    多态)         Lambda/移动语义)
     │
     ▼
04 STL 标准库 ──→ 05 高级主题 ──→ 06 实战练习
(容器/算法/    (多线程/      (成绩管理/
 迭代器)       内存/模板)     计算器/生产消费)
```

## 🛠️ 环境准备

| 工具 | 推荐选择 | 说明 |
|------|----------|------|
| 编译器 | GCC 9+ / Clang | 支持 C++17 |
| IDE/编辑器 | VS Code + C++ 插件 | 轻量、免费 |
| 备选 IDE | CLion | 功能强大，学生免费 |
| 构建工具 | CMake | ROS 必备 |
| 调试器 | GDB | 学调试必备 |

### 快速验证环境
```bash
# 检查 GCC 版本
g++ --version

# 编译第一个程序
g++ -std=c++17 -o hello hello.cpp
```

### 书籍（按学习顺序）

2. **《Effective Modern C++》**— 现代 C++ 必读

- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) — C++ 最佳实践
