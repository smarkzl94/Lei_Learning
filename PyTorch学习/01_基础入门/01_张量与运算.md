## 📚 核心知识点

### 1. 什么是张量

张量是 PyTorch 的核心数据结构，本质上是**可自动求导、可跑在 GPU 上的多维数组**。

| 维度 | 名称 | 例子 | shape |
|------|------|------|-------|
| 0 维 | 标量 | 损失值 | `()` |
| 1 维 | 向量 | 偏置 bias | `(features,)` |
| 2 维 | 矩阵 | 权重矩阵 | `(in, out)` |
| 3 维 | 张量 | 序列/特征图 | `(seq, batch, dim)` |
| 4 维 | 张量 | 图像批次 | `(N, C, H, W)` |

> **记忆**：图像在 PyTorch 里永远是 `(批次, 通道, 高, 宽)` 即 NCHW 格式。

### 2. 创建张量

```python
import torch

torch.tensor([[1, 2], [3, 4]])        # 从数据创建
torch.zeros(3, 4)                     # 全 0
torch.ones(2, 3)                      # 全 1
torch.rand(2, 3)                      # [0,1) 均匀分布
torch.randn(2, 3)                     # 标准正态分布（权重初始化常用）
torch.arange(0, 10, 2)                # [0, 2, 4, 6, 8]
torch.linspace(0, 1, 5)               # 等间距 5 个数
x.new_ones(2)                         # 继承 x 的类型和设备
torch.full((2, 3), 7)                 # 填充指定值
```

### 3. 常用属性与类型

```python
x = torch.randn(2, 3)
x.shape      # torch.Size([2, 3])
x.dtype      # torch.float32（默认浮点类型）
x.device     # cpu 或 cuda:0
x.requires_grad  # 是否追踪梯度

# 类型转换
x.float()  x.long()  x.half()
x.to(torch.float64)
```

常用 dtype：`float32`（默认）、`float16`（混合精度训练）、`int64/long`（标签、索引）、`bool`。

### 4. 形状操作（高频）

```python
x = torch.randn(4, 3, 32, 32)

x.view(4, -1)          # 改变形状，-1 自动推断 → (4, 3072)
x.reshape(12, 32, 32)  # 与 view 类似，但允许非连续内存
x.flatten(1)           # 从第 1 维开始展平 → (4, 3072)
x.permute(0, 2, 3, 1)  # 维度换序 NCHW→NHWC
x.transpose(1, 2)      # 交换两个维度
x.squeeze()            # 去掉所有长度为 1 的维
x.unsqueeze(0)         # 在第 0 维增加一维
x.unsqueeze(0).expand(8, -1, -1, -1)  # 扩展（不复制内存）
```

### 5. 索引与切片

规则与 NumPy 完全一致：

```python
x[0]            # 第 0 个样本
x[:, 0]         # 所有样本的第 0 通道
x[1:3, :, 8:24] # 组合切片
x[x > 0]        # 布尔掩码
idx = torch.tensor([0, 2])
x[idx]          # 花式索引
torch.masked_select(x, x > 0)
torch.gather(x, dim, index)   # 按索引收集（分类任务取概率常用）
```

### 6. 数学运算

```python
# 逐元素运算
a + b   torch.add(a, b)
a * b   # 逐元素乘（不是矩阵乘！）
a @ b   torch.matmul(a, b)    # 矩阵乘法
a.pow(2)  a.sqrt()  a.exp()  a.log()

# 聚合运算
x.sum()  x.mean()  x.max()  x.min()
x.sum(dim=1)          # 沿维度聚合，维度会消失
x.sum(dim=1, keepdim=True)  # 保留维度（便于广播）
x.argmax(dim=1)       # 分类预测最常用

# 比较
torch.eq(a, b)  (a > b)
torch.topk(x, k=5, dim=1)     # Top-5 准确率用
```

### 7. 广播机制（Broadcasting）

形状不同的张量运算时自动扩展，规则：**从右往左对齐维度，维度为 1 或缺失的可广播**。

```python
x = torch.randn(4, 3)     # (4, 3)
b = torch.randn(3)        # (3,) → 广播成 (4, 3)
x + b                     # 合法

x = torch.randn(4, 1)
y = torch.randn(1, 3)
x + y                     # (4, 3) 双向广播
```

### 8. GPU 加速

```python
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

x = x.to(device)              # 张量上 GPU
model = model.to(device)      # 模型上 GPU

# 注意：运算双方必须在同一设备
# cpu_tensor + cuda_tensor → RuntimeError
```

### 9. 与 NumPy 互转

```python
import numpy as np
a = np.array([1, 2, 3])
t = torch.from_numpy(a)   # 共享内存！改一个另一个也变
b = t.numpy()             # 仅 CPU 张量可直接转
```

> ⚠️ `from_numpy` 共享内存是特性也是坑，需要独立副本时用 `.clone()`。

## 💻 实战练习

```python
# 练习：手写一个线性层的正向传播 y = xW + b
x = torch.randn(64, 784)        # batch=64, 输入 784 维
W = torch.randn(784, 128)
b = torch.randn(128)

y = x @ W + b                   # (64, 128) —— b 自动广播
print(y.shape)
```

## ⚠️ 常见坑

1. `view` 要求内存连续，报错乱用前先 `.contiguous()`，或直接用 `reshape`
2. 默认 `float32`，而标签索引要 `long`，类型不匹配是最常见报错
3. `torch.dot` 只能算 1 维向量点积；矩阵乘法用 `@` / `matmul`
4. 设备不一致：`模型在 cuda、数据在 cpu` 会直接报错
