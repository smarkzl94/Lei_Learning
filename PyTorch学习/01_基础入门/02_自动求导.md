## 📚 核心知识点

### 1. 为什么需要自动求导

深度学习训练 = 前向算损失 + **反向算梯度** + 更新参数。手动推导每层梯度不现实，PyTorch 的 **autograd** 通过动态计算图自动完成反向传播。

```
前向：x → [运算] → y → [运算] → loss   （边算边建图）
反向：loss → ∂loss/∂y → ∂loss/∂x       （链式法则，沿图回传）
```

### 2. requires_grad：让张量被追踪

```python
import torch

x = torch.tensor([2.0], requires_grad=True)  # 声明：我要对 x 求导
y = x ** 2 + 3 * x
y.backward()          # 反向传播，y 是标量时无需传参
print(x.grad)         # dy/dx = 2x + 3 = 7.0
```

- 只有 `requires_grad=True` 的张量参与建图
- 模型参数（`nn.Parameter` / 各层权重）默认 `True`
- 只有**浮点类型**才能求导

### 3. backward() 的规则

```python
# 情况1：标量（loss）直接 backward
loss.backward()

# 情况2：非标量必须传 gradient 参数（外推权重向量）
y = x ** 2              # y 是向量
y.backward(torch.ones_like(x))   # 等价于对 y.sum() 求导
```

### 4. 梯度累积与清零（最高频的坑）

PyTorch 的梯度是**累加**的，不会自动覆盖：

```python
for data, target in loader:
    output = model(data)
    loss = criterion(output, target)

    optimizer.zero_grad()   # ← 必须！否则梯度越加越大
    loss.backward()         # 梯度累加到 .grad
    optimizer.step()        # 用梯度更新参数
```

> 忘写 `zero_grad()` 是新手第一大坑：loss 下降异常、梯度爆炸。

梯度累积也可用来**模拟大 batch**（显存不够时）：

```python
accum_steps = 4
for i, (data, target) in enumerate(loader):
    loss = model(data).sum() / accum_steps
    loss.backward()                      # 故意不清零，梯度累加
    if (i + 1) % accum_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

### 5. 三件套：no_grad / detach / requires_grad_(False)

| 需求 | 用法 | 场景 |
|------|------|------|
| 临时不求导 | `with torch.no_grad():` | **验证/测试**时包住整个前向 |
| 永久不求导 | `param.requires_grad_(False)` | 冻结预训练模型的部分层 |
| 从图中拆出来 | `x = y.detach()` | 把张量当纯数据用（共享内存） |

```python
# 验证阶段标准写法
model.eval()
with torch.no_grad():          # 不建图，省显存、加速
    for data, target in test_loader:
        output = model(data)

# 微调时冻结 backbone
for param in model.backbone.parameters():
    param.requires_grad_(False)
```

### 6. 计算图的生命周期

- `backward()` 后计算图**默认被释放**，再次对同一图 backward 会报错
- 需要多次反向时：`loss.backward(retain_graph=True)`
- 训练循环中每次迭代都会重新前向、**重新建图**，所以正常循环不受影响

### 7. 查看梯度与调试

```python
print(model.fc1.weight.grad)          # 看参数梯度
x.grad_fn                              # 看创建该张量的运算
x.is_leaf                              # 是否叶子节点

# 梯度为 None 的常见原因：
# 1. 没写 requires_grad=True
# 2. 中间用了 detach() / .item() / numpy() 断开了图
# 3. 该参数没参与 loss 的计算
```

`.item()` 把单元素张量转成 Python 数值，用于记录 loss：

```python
total_loss += loss.item()   # 对！断开图，只取数值
total_loss += loss          # 错！拖着整个计算图，显存泄漏
```

## 💻 实战练习

```python
# 手动实现一次完整的参数更新（不用 optimizer）
w = torch.tensor([1.0], requires_grad=True)
lr = 0.1

for epoch in range(10):
    loss = (w * 3 - 9) ** 2      # 目标：让 w 趋近 3
    loss.backward()
    with torch.no_grad():         # 更新参数时不能建图
        w -= lr * w.grad
    w.grad.zero_()                # 清零，准备下一轮

print(w.item())  # ≈ 3.0
```

## ⚠️ 常见坑

1. 训练循环忘 `optimizer.zero_grad()` → 梯度累积
2. 验证循环忘 `torch.no_grad()` → 显存爆炸
3. 记录 loss 直接加张量不加 `.item()` → 内存泄漏
4. 用 `x.data` 绕过图（老代码）→ 改用 `detach()` 更安全

---

## 📝 小结

- autograd = 动态建图 + 链式法则反向传播
- 训练五步：`zero_grad → forward → loss → backward → step`
- 验证必包 `no_grad`，取数值用 `.item()`
