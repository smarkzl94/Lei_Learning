## 🧱 第 0 课：零基础补课（损失函数和优化器是什么）

前面你已经分别见过零件了：模型（03 章）、loss/backward/梯度（02 章）、`w -= lr * w.grad` 手动更新（practice02 任务 3）。这一章就是把零件组装成一台完整机器，并引入两个新角色。

### 0.1 损失函数（criterion）= 阅卷老师

你已经在 practice02 里见过 loss 了（`(w*3-9)²`），但那是随手写的。真实训练需要一个**标准化的"阅卷标准"**，告诉模型"你的预测错得有多离谱"：

| 任务类型           | 阅卷标准（损失函数）               | 举例     |
| -------------- | ------------------------ | ------ |
| 多分类（猫/狗/鸟…选其一） | `nn.CrossEntropyLoss()`  | 图片分类   |
| 二分类（是/否）       | `nn.BCEWithLogitsLoss()` | 垃圾邮件识别 |
| 回归（预测连续数值）     | `nn.MSELoss()`           | 预测房价   |

**分类问题就用 CrossEntropyLoss，先不用管公式**，把它当"标准阅卷老师"用就行：

```python
criterion = nn.CrossEntropyLoss()
loss = criterion(模型输出的分数, 正确答案编号)   # 返回一个数：错得有多离谱
```

### 0.2 优化器（optimizer）= 替你拧旋钮的机械手

practice02 任务 3 里你手写了一步更新：

```python
with torch.no_grad():
    w -= lr * w.grad          # 手动拧旋钮
```

模型有上百万参数后，手动拧不现实。**优化器就是帮你批量拧旋钮的机械手**——你只需在循环开头造一个它，之后每轮调用 `optimizer.step()`，它就把所有参数按梯度拧一遍：

```python
import torch.optim as optim

optimizer = optim.SGD([w], lr=0.1)   # 告诉它：管哪些参数、步子多大（lr）
loss.backward()                       # 梯度算好
optimizer.step()                      # 机械手自动拧所有参数
```

**注意一个细节**：机械手只管拧，不管清零。梯度清零（`zero_grad()`）还是要你每轮手动喊——这就是训练五步里第一步的由来。

### 0.3 学习率调度 = 先大步后小步

训练前期离最低点远，可以大步走（学得快）；后期接近最低点，要换成小步（防止在最低点附近来回震荡、踩不准）。

\*\*学习率调度器（scheduler）\*\*就是干这个的：让学习率随训练进程自动衰减。好比"行程过半，收油门"。

### 0.4 本节只需要记住三句话

1. 损失函数 = 阅卷老师（CrossEntropyLoss 管多分类）
2. 优化器 = 拧参数的机械手（AdamW 是默认首选），但清零要自己喊
3. 调度器 = 让步子先大后小

## 📚 核心知识点

### 1. 训练流水线全景

```
数据(DataLoader) → 前向(model) → 损失(criterion) → 反传(backward) → 更新(optimizer)
                                                                      ↓
                                              验证(eval+no_grad) ← 调度器(scheduler)
```

这一章学完，这张图上每个环节你都能写出代码。

### 2. 标准训练循环（背下来）⭐

```python
for epoch in range(num_epochs):
    # ===== 训练阶段 =====
    model.train()
    train_loss = 0.0
    for data, target in train_loader:
        data, target = data.to(device), target.to(device)

        optimizer.zero_grad()          # 1. 清梯度
        output = model(data)           # 2. 前向
        loss = criterion(output, target)  # 3. 算损失
        loss.backward()                # 4. 反传
        optimizer.step()               # 5. 更新

        train_loss += loss.item()

    # ===== 验证阶段 =====
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for data, target in val_loader:
            data, target = data.to(device), target.to(device)
            output = model(data)
            pred = output.argmax(dim=1)
            correct += (pred == target).sum().item()
            total += target.size(0)

    acc = correct / total
    scheduler.step()                   # 更新学习率
    print(f"Epoch {epoch}: loss={train_loss/len(train_loader):.4f}, acc={acc:.4f}")
```

**两个阶段的对比是理解的关键：**

| <br /> | 训练阶段            | 验证阶段                           |
| ------ | --------------- | ------------------------------ |
| 模式     | `model.train()` | `model.eval()`                 |
| 录音     | 开（要算梯度）         | **关**（`torch.no_grad()`，省显存加速） |
| 目的     | 更新参数            | 只评估，**不更新**                    |
| 指标     | loss            | 准确率 accuracy                   |

验证的本质就是"模拟考试"：做题、对答案，但**不改任何参数**。所以连梯度都不用算（no\_grad）。

### 3. 损失函数选择

| 任务   | 损失函数                           | 输入要求                        |
| ---- | ------------------------------ | --------------------------- |
| 多分类  | `nn.CrossEntropyLoss()`        | logits(未过softmax) + long 标签 |
| 二分类  | `nn.BCEWithLogitsLoss()`       | logit + float 标签            |
| 回归   | `nn.MSELoss()` / `L1Loss()`    | 预测值 + 目标值                   |
| 语义分割 | `CrossEntropyLoss` / Dice Loss | 逐像素分类                       |

```python
criterion = nn.CrossEntropyLoss()
# ⚠️ 它内部已含 LogSoftmax，模型最后一层不要再加 Softmax！
# 加了会数值不稳定且梯度错误

# 类别不均衡：给类加权
criterion = nn.CrossEntropyLoss(weight=torch.tensor([1.0, 5.0]).to(device))
```

**"logits"是什么？** 就是模型最后一层直接输出的"原始分数"——还没归一化成概率的那些数。CrossEntropyLoss 要的正是这个，**千万别先过 softmax**。

### 4. 优化器

```python
import torch.optim as optim

optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9, weight_decay=5e-4)
optimizer = optim.Adam(model.parameters(), lr=1e-3)            # 自适应，默认首选
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)  # Transformer 标配
```

* **SGD+momentum**：泛化好，CNN 传统选择，需要调 lr

* **Adam/AdamW**：收敛快、对 lr 不敏感，默认就用它

* 不同层不同学习率（微调时常用）：

```python
optimizer = optim.AdamW([
    {'params': model.backbone.parameters(), 'lr': 1e-5},   # 预训练层小 lr
    {'params': model.head.parameters(),     'lr': 1e-3},   # 新层大 lr
])
```

**`model.parameters()` 是什么？** 03 章说过：收纳箱自动登记了所有参数。这里把它整个交给优化器——一句话完成"机械手接管所有旋钮"。

### 5. 学习率调度器

```python
# 按 epoch 衰减
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)
scheduler.step()   # 每个 epoch 末尾调用

# 余弦退火（现在最常用）
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=num_epochs)

# 按验证指标衰减
scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, patience=5)
scheduler.step(val_loss)   # 注意：这个要传指标
```

### 6. 完整训练脚本的骨架

```python
def main():
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    best_acc = 0.0

    model = MyModel().to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.AdamW(model.parameters(), lr=1e-3)
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)

    for epoch in range(epochs):
        train_one_epoch(...)
        acc = validate(...)

        if acc > best_acc:                        # 只保存最优
            best_acc = acc
            torch.save({
                'epoch': epoch,
                'model': model.state_dict(),
                'optimizer': optimizer.state_dict(),
                'acc': best_acc,
            }, 'best.pth')

# 断点续训
ckpt = torch.load('best.pth')
model.load_state_dict(ckpt['model'])
optimizer.load_state_dict(ckpt['optimizer'])
```

**为什么只存 best 不存每个 epoch？** 模型文件几十 MB\~几 GB，每个 epoch 存一次硬盘很快爆。而且验证集上最准的那版才是你要的——训练越久不一定越好（可能开始死记硬背训练集）。

### 7. 性能与显存技巧

```python
# 混合精度训练（显存减半、速度翻倍，现代标配）
scaler = torch.amp.GradScaler('cuda')
with torch.amp.autocast('cuda'):
    output = model(data)
    loss = criterion(output, target)
scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()

# 梯度裁剪（RNN/Transformer 防爆）
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

## ⚠️ 常见坑

1. 忘 `zero_grad()` → 梯度累积（第 02 章强调过）
2. `CrossEntropyLoss` 前手动加 Softmax → 损失错误
3. 标签类型不是 `long` → 报 dtype 错
4. 验证时忘 `model.eval()` + `no_grad()` → 指标不准、显存爆炸
5. 每个 epoch 都存模型 → 硬盘爆炸，只存 best
