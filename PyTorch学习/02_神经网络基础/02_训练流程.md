## 📚 核心知识点

### 1. 训练流水线全景

```
数据(DataLoader) → 前向(model) → 损失(criterion) → 反传(backward) → 更新(optimizer)
                                                                      ↓
                                              验证(eval+no_grad) ← 调度器(scheduler)
```

### 2. 标准训练循环（背下来）

```python
for epoch in range(num_epochs):
    # ===== 训练阶段 =====
    model.train()
    train_loss = 0.0
    for data, target in train_loader:
        data, target = data.to(device), target.to(device)

        optimizer.zero_grad()          # 1. 清梯度
        output = model(data)           # 2. 前向
        loss = criterion(output, target)  # 3. 算损失
        loss.backward()                # 4. 反传
        optimizer.step()               # 5. 更新

        train_loss += loss.item()

    # ===== 验证阶段 =====
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for data, target in val_loader:
            data, target = data.to(device), target.to(device)
            output = model(data)
            pred = output.argmax(dim=1)
            correct += (pred == target).sum().item()
            total += target.size(0)

    acc = correct / total
    scheduler.step()                   # 更新学习率
    print(f"Epoch {epoch}: loss={train_loss/len(train_loader):.4f}, acc={acc:.4f}")
```

### 3. 损失函数选择

| 任务 | 损失函数 | 输入要求 |
|------|----------|----------|
| 多分类 | `nn.CrossEntropyLoss()` | logits(未过softmax) + long 标签 |
| 二分类 | `nn.BCEWithLogitsLoss()` | logit + float 标签 |
| 回归 | `nn.MSELoss()` / `L1Loss()` | 预测值 + 目标值 |
| 语义分割 | `CrossEntropyLoss` / Dice Loss | 逐像素分类 |

```python
criterion = nn.CrossEntropyLoss()
# ⚠️ 它内部已含 LogSoftmax，模型最后一层不要再加 Softmax！
# 加了会数值不稳定且梯度错误

# 类别不均衡：给类加权
criterion = nn.CrossEntropyLoss(weight=torch.tensor([1.0, 5.0]).to(device))
```

### 4. 优化器

```python
import torch.optim as optim

optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9, weight_decay=5e-4)
optimizer = optim.Adam(model.parameters(), lr=1e-3)            # 自适应，默认首选
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)  # Transformer 标配
```

- **SGD+momentum**：泛化好，CNN 传统选择，需要调 lr
- **Adam/AdamW**：收敛快、对 lr 不敏感，默认就用它
- 不同层不同学习率（微调时常用）：

```python
optimizer = optim.AdamW([
    {'params': model.backbone.parameters(), 'lr': 1e-5},   # 预训练层小 lr
    {'params': model.head.parameters(),     'lr': 1e-3},   # 新层大 lr
])
```

### 5. 学习率调度器

```python
# 按 epoch 衰减
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)
scheduler.step()   # 每个 epoch 末尾调用

# 余弦退火（现在最常用）
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=num_epochs)

# 按验证指标衰减
scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, patience=5)
scheduler.step(val_loss)   # 注意：这个要传指标
```

### 7. 性能与显存技巧

```python
# 混合精度训练（显存减半、速度翻倍，现代标配）
scaler = torch.amp.GradScaler('cuda')
with torch.amp.autocast('cuda'):
    output = model(data)
    loss = criterion(output, target)
scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()

# 梯度裁剪（RNN/Transformer 防爆）
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

optimizer.zero_grad()
loss = criterion(model(data), target)
loss.backward()

## ⚠️ 常见坑

1. 忘 `zero_grad()` → 梯度累积（第 02 章强调过）
2. `CrossEntropyLoss` 前手动加 Softmax → 损失错误
3. 标签类型不是 `long` → 报 dtype 错
4. 验证时忘 `model.eval()` + `no_grad()` → 指标不准、显存爆炸
5. 每个 epoch 都存模型 → 硬盘爆炸，只存 best

## 📝 小结

- 五步循环：清梯度 → 前向 → 损失 → 反传 → 更新
- 分类默认 `CrossEntropyLoss + AdamW + CosineAnnealingLR`
- 训练 `train()`，验证 `eval()` + `no_grad()`
