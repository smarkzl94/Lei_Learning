## 📚 核心知识点

### 1. 为什么要增强

模型见过的"变化"越多，泛化越强。同一张猫图，翻转、裁剪、变色后模型仍能认出 → 学到的是**本质特征**而不是死记像素。

> 本质：用免费的变换人为扩大训练集规模，是最便宜的正则化手段。

### 2. transforms.Compose 流水线

```python
from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),        # 随机裁剪再缩放到 224（最强增强之一）
    transforms.RandomHorizontalFlip(p=0.5),   # 50% 概率水平翻转
    transforms.ColorJitter(brightness=0.2,    # 随机亮度/对比度/饱和度
                           contrast=0.2,
                           saturation=0.2),
    transforms.RandomRotation(15),            # 随机旋转 ±15°
    transforms.ToTensor(),                    # PIL → Tensor，且 /255 归一
    transforms.Normalize(mean=[0.485, 0.456, 0.406],   # ImageNet 统计值
                         std=[0.229, 0.224, 0.225]),
])
```

**顺序很重要**：几何变换(PIL) → ToTensor → Normalize。ToTensor 之后是张量，PIL 专属变换就不能用了。

### 3. 训练 vs 验证：两套必须分开

```python
train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),    # 随机！增加多样性
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])

val_transform = transforms.Compose([
    transforms.Resize(256),               # 确定性！保证结果可复现
    transforms.CenterCrop(224),           # 中心裁剪
    transforms.ToTensor(),
    transforms.Normalize(mean, std),      # 必须与训练一致！
])
```

> ⚠️ **验证集绝不做随机增强**，但 Normalize 的 mean/std 必须与训练完全一致。

### 4. Normalize 的原理

`output = (input - mean) / std`，把各通道拉成零均值单位方差：

- 让不同通道数值范围一致，梯度下降更稳
- 用预训练模型时**必须用该模型的 mean/std**（ImageNet: `[0.485,0.456,0.406]` / `[0.229,0.224,0.225]`）
- 自己从头训练可以算自己数据集的统计量

### 5. 常用变换速查表

| 变换 | 作用 | 适用 |
|------|------|------|
| `RandomResizedCrop` | 随机裁剪+缩放 | 图像分类首选 |
| `RandomHorizontalFlip` | 水平翻转 | 通用（文字/医学慎用） |
| `RandomRotation` | 随机旋转 | 通用 |
| `ColorJitter` | 颜色扰动 | 光照多变的场景 |
| `RandomAffine` | 平移+旋转+缩放 | 通用 |
| `RandomErasing` | 随机遮挡一块 | 防过拟合（ToTensor后用） |
| `Resize + CenterCrop` | 确定性预处理 | 验证/测试 |
| `RandomGrayscale` | 随机转灰度 | 颜色无关任务 |

### 6. 进阶增强（了解）

```python
# RandAugment：自动组合增强策略，一行搞定
train_transform = transforms.Compose([
    transforms.RandAugment(num_ops=2, magnitude=9),
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])

# Mixup / CutMix：样本级混合，需在训练循环里对 batch 操作（不在 transform 里）
```

### 7. 增强的目标检测/分割场景

分类只变图不变标签；检测要**同步变换 bbox**，分割要**同步变换 mask**：

```python
# 用 torchvision.transforms.v2 或 albumentations 库
import albumentations as A
transform = A.Compose([
    A.RandomCrop(224, 224),
    A.HorizontalFlip(p=0.5),
], bbox_params=A.BboxParams(format='pascal_voc'))   # bbox 跟着一起变
```

## 💻 实战练习

```python
# 可视化增强效果：同一张图增强 8 次，肉眼检查是否破坏了语义
from PIL import Image
import matplotlib.pyplot as plt

img = Image.open('cat.jpg')
fig, axes = plt.subplots(2, 4, figsize=(12, 6))
for ax in axes.flat:
    aug = train_transform(img)
    ax.imshow(aug.permute(1, 2, 0) * 0.5 + 0.5)  # 反归一化近似显示
    ax.axis('off')
plt.show()
```

## ⚠️ 常见坑

1. 验证集用了随机增强 → 每次评估结果都不一样
2. Normalize 用错统计值（尤其加载预训练模型时）→ 精度直接掉几个点
3. 对测试集标签敏感的变换乱用：手写数字 6/9 不能做翻转！
4. `ToTensor()` 放在 Normalize 后面 → 报错（顺序错了）

## 📝 小结

- 增强 = 最便宜的正则化；训练随机、验证确定
- 标准配置：`RandomResizedCrop + RandomHorizontalFlip + ToTensor + Normalize`
- Normalize 的 mean/std 跟预训练模型走
