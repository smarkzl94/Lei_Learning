## 📚 核心知识点

### 1. 实战总流程

```
准备数据(ImageFolder) → 数据增强 → 加载预训练模型 → 替换分类头
→ 冻结/微调 → 训练 → 验证评估 → 保存 → 推理部署
```

### 2. 迁移学习：站在巨人肩膀上

小数据集（几千张）不要从头训练，直接微调 ImageNet 预训练模型：

```python
from torchvision import models
import torch.nn as nn

model = models.resnet18(weights='IMAGENET1K_V1')   # 加载预训练权重

# 方案A：冻结特征层，只训分类头（数据极少时）
for param in model.parameters():
    param.requires_grad_(False)

# 替换最后的全连接层（ResNet 的分类层叫 fc）
in_features = model.fc.in_features
model.fc = nn.Linear(in_features, 2)     # 改成自己的类别数，新层默认可训练
```

```python
# 方案B：分层学习率微调（数据几千张时，效果更好）
optimizer = torch.optim.AdamW([
    {'params': model.layer4.parameters(), 'lr': 1e-4},   # 深层小步微调
    {'params': model.fc.parameters(),     'lr': 1e-3},   # 新分类头大步学
], weight_decay=0.01)
```

**何时解冻多少**：

| 数据量 | 策略 |
|--------|------|
| < 1 千张 | 全冻结，只训分类头 |
| 1千~1万 | 解冻最后 1~2 个 block |
| > 10 万 | 可以考虑全量微调 |

### 3. 完整训练脚本（猫狗分类模板）

```python
import torch, torch.nn as nn
from torchvision import datasets, transforms, models
from torch.utils.data import DataLoader

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
mean, std = [0.485, 0.456, 0.406], [0.229, 0.224, 0.225]   # ImageNet 统计值

train_tf = transforms.Compose([
    transforms.RandomResizedCrop(224), transforms.RandomHorizontalFlip(),
    transforms.ToTensor(), transforms.Normalize(mean, std),
])
val_tf = transforms.Compose([
    transforms.Resize(256), transforms.CenterCrop(224),
    transforms.ToTensor(), transforms.Normalize(mean, std),
])

train_set = datasets.ImageFolder('data/train', train_tf)
val_set   = datasets.ImageFolder('data/val', val_tf)
train_loader = DataLoader(train_set, 32, shuffle=True,  num_workers=4)
val_loader   = DataLoader(val_set,   32, shuffle=False, num_workers=4)

model = models.resnet18(weights='IMAGENET1K_V1')
model.fc = nn.Linear(model.fc.in_features, len(train_set.classes))
model = model.to(device)

criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=10)

best_acc = 0.0
for epoch in range(10):
    model.train()
    for imgs, labels in train_loader:
        imgs, labels = imgs.to(device), labels.to(device)
        optimizer.zero_grad()
        loss = criterion(model(imgs), labels)
        loss.backward()
        optimizer.step()

    model.eval()
    correct = total = 0
    with torch.no_grad():
        for imgs, labels in val_loader:
            imgs, labels = imgs.to(device), labels.to(device)
            correct += (model(imgs).argmax(1) == labels).sum().item()
            total += labels.size(0)
    acc = correct / total
    scheduler.step()

    if acc > best_acc:
        best_acc = acc
        torch.save(model.state_dict(), 'best.pth')
    print(f"Epoch {epoch}: val_acc = {acc:.4f}")
```

### 4. 过拟合的判断与对策

**判断**：训练 acc 98%、验证 acc 75% → 典型过拟合。

| 对策 | 做法 |
|------|------|
| 数据增强 | 加强 RandomResizedCrop / RandAugment |
| Dropout | 分类头前加 `nn.Dropout(0.5)` |
| 权重衰减 | optimizer 的 `weight_decay` 调大 |
| Early Stopping | 验证指标连续 N 轮不涨就停 |
| 更多数据 | 永远是最有效的 |

**欠拟合**（训练和验证都差）：加大模型、减小正则、训更久、调大 lr。

### 6. 推理与部署

model.eval()
img = val_tf(Image.open('test.jpg').convert('RGB')).unsqueeze(0).to(device)
with torch.no_grad():
    prob = model(img).softmax(dim=1)
    conf, pred = prob.max(1)

## ⚠️ 常见坑

1. Normalize 没用 ImageNet 统计值 → 预训练权重白加载
2. 忘了替换 `model.fc` 就直接训练 → 输出 1000 类对不上标签
3. 数据文件夹放错层级：`data/train/cat/*.jpg` 才对，多嵌套一层 ImageFolder 读不到
4. 验证时忘 `model.eval()` → BN/Dropout 行为错乱
