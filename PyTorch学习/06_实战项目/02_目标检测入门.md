## 📚 核心知识点

### 1. 任务定位

| 任务 | 输出 | 问题 |
|------|------|------|
| 分类 | 类别 | 图里"是什么" |
| 检测 | 类别 + bbox | 图里"有什么、在哪里" |
| 分割 | 逐像素掩码 | 精确的轮廓 |

bbox 两种表示：`(x1, y1, x2, y2)` 左上角+右下角；`(cx, cy, w, h)` 中心+宽高。注意各框架默认格式不同！

### 2. IoU：检测的基石指标

交并比 = 两框交集面积 ÷ 并集面积，衡量预测框与真值框的重合度：

```python
def iou(box1, box2):  # (x1,y1,x2,y2)
    x1 = max(box1[0], box2[0]); y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2]); y2 = min(box1[3], box2[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area1 = (box1[2]-box1[0]) * (box1[3]-box1[1])
    area2 = (box2[2]-box2[0]) * (box2[3]-box2[1])
    return inter / (area1 + area2 - inter + 1e-6)
```

用途：判断预测正确与否（IoU > 0.5 算命中）、NMS 去重、mAP 计算。

### 3. NMS：非极大值抑制

同一个目标会被预测出多个重叠框，NMS 留下最好的：

1. 按置信度排序
2. 取最高分的框，删掉与它 IoU > 阈值的所有框
3. 对剩余框重复，直到清空

```python
from torchvision.ops import nms
keep = nms(boxes, scores, iou_threshold=0.5)
```

### 4. 检测器演进（了解谱系）

```
两阶段（先提候选框再分类）：
R-CNN → Fast R-CNN → Faster R-CNN ← 精度高，速度慢
单阶段（直接回归）：
YOLO 系列 / SSD / RetinaNet      ← 速度快，工业首选
无锚框/Transformer：
FCOS / DETR                      ← 去掉手工锚框设计
```

**Faster R-CNN**：RPN 网络自动生成候选框 + 检测头分类回归。
**YOLO**：把图分成网格，每个网格直接预测框和类别，一次前向出结果。

### 5. 用预训练模型做检测（5 行推理）

```python
from torchvision.models.detection import fasterrcnn_resnet50_fpn
import torchvision.transforms as T
from PIL import Image

model = fasterrcnn_resnet50_fpn(weights='DEFAULT').eval()
img = T.ToTensor()(Image.open('street.jpg').convert('RGB'))

with torch.no_grad():
    out = model([img])[0]
# out: dict，含 boxes (N,4)、labels (N,)、scores (N,)

keep = out['scores'] > 0.8
boxes, labels = out['boxes'][keep], out['labels'][keep]
```

标签对应 COCO 80 类（1=person, 3=car, 17=cat...），torchvision 提供 `COCO_INSTANCE_CATEGORY_NAMES`。

### 6. 检测训练的损失（概念）

检测 = 多任务学习，损失通常三部分加和：

```
L = L_cls + λ·L_box (+ L_obj)
     分类      框回归      有无目标置信度
```

- 分类：CrossEntropy / Focal Loss（解决正负样本极不均衡）
- 回归：Smooth L1 / GIoU / CIoU Loss

### 7. 数据集格式

| 格式 | 结构 | 代表数据集 |
|------|------|-----------|
| COCO | 一个大 JSON：images + annotations | COCO |
| VOC | 每张图一个 XML | Pascal VOC |
| YOLO | 每张图一个 txt：`class cx cy w h`（归一化） | 自定义最常用 |

自己标数据用 **labelImg / Label Studio / roboflow**，导出 YOLO 格式最省事。

### 8. 评估指标 mAP

- 单类：IoU 阈值下 P-R 曲线下面积（AP）
- 全体：各类 AP 平均（mAP）
- COCO 标准：IoU 从 0.5 到 0.95 取平均（mAP@[.5:.95]）

> 工程建议：**不要自己从零写检测训练**。用 Ultralytics YOLO / MMDetection 等成熟框架，几行配置就能训练。

## 💻 实战练习

```python
# 给检测结果画框可视化
import torchvision.utils as vutils
from PIL import ImageDraw

# 或更简单：
from torchvision.utils import draw_bounding_boxes
import torchvision.transforms.functional as F
vis = draw_bounding_boxes(
    (img * 255).to(torch.uint8), boxes,
    labels=[str(l.item()) for l in labels], colors='red', width=3)
F.to_pil_image(vis).save('result.jpg')
```

## ⚠️ 常见坑

1. bbox 格式混乱（xyxy vs cxcywh、归一化 vs 像素）→ 框全歪
2. 数据增强只变图没变 bbox → 标签错位（见 06 章）
3. 小数据集从零训检测器 → 不如用预训练模型微调
4. 忘了 NMS → 一个目标一堆框

---

## 📝 小结

- 检测 = 分类 + 定位；IoU 是基础度量，NMS 去重
- 两阶段求精度、单阶段求速度；工程直接用 YOLO 类框架
- 自己标数据用 YOLO txt 格式最通用
