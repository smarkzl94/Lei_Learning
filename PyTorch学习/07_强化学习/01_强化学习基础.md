## 📚 核心知识点

### 1. 与监督学习的本质区别

| | 监督学习 | 强化学习 |
|---|----------|----------|
| 信号 | 正确答案（标签） | 奖励（可能延迟、稀疏） |
| 数据 | 静态数据集 | 智能体与环境交互产生 |
| 目标 | 拟合映射 f(x)→y | 最大化长期累计奖励 |
| 例子 | 看图识猫 | 下棋、机器人控制、游戏 |

### 2. 核心五要素

```
智能体(Agent) ──动作 a──→ 环境(Environment)
    ↑                        │
    └──状态 s, 奖励 r ←──────┘
```

- **State s**：环境当前状态（棋盘局面、机器人传感器读数）
- **Action a**：智能体可选操作（上下左右、关节力矩）
- **Reward r**：环境的即时反馈分数
- **Policy π(a|s)**：策略——在状态 s 下选各动作的概率（**智能体的大脑，要学习的就是它**）
- **Return G**：长期回报 = r₀ + γr₁ + γ²r₂ + ...（γ 是折扣因子，0.9~0.99）

> γ 的含义：γ→0 只看眼前（短视），γ→1 远近同样看重（耐心）。

### 3. 马尔可夫决策过程（MDP）

核心假设：**未来只取决于当前状态，与历史无关**。

```
P(s', r | s, a)   在状态 s 执行 a，转移到 s' 并得到 r 的概率
```

RL 的目标：找到最优策略 π\* 使期望回报最大。

### 4. 价值函数：给状态/动作打分

- **V(s)**：状态价值——从 s 出发按策略 π 走下去，期望回报多少
- **Q(s, a)**：动作价值——在 s 先做 a，再按 π 走，期望回报多少

**贝尔曼方程**（一切 RL 算法的根基）：

```
Q(s,a) = r + γ · max_a' Q(s', a')
当前价值 = 即时奖励 + 折扣后的未来最优价值
```

直觉：一个动作好不好 = 眼前奖励 + 它带你去的那个状态有多好。

### 5. Q-Learning：表格版 RL

用一张表存所有 Q(s,a)，不断用贝尔曼方程修正：

```python
# Q-Learning 更新公式（背诵）
Q(s,a) += α * (r + γ * max(Q(s', :)) - Q(s,a))
#              └────── TD 目标 ──────┘ └当前┘
#        学习率 ×   （新估计 − 旧估计）
```

- α：学习率；γ：折扣因子
- **异策略(off-policy)**：学的是 max 的贪心目标，行动时可以探索

### 6. ε-greedy：探索与利用的平衡

```python
if random.random() < epsilon:
    action = env.action_space.sample()    # 探索：随机试
else:
    action = np.argmax(Q[state])          # 利用：选当前最优
```

- ε 通常从 1.0 随训练衰减到 0.05 左右
- 纯利用 → 陷入局部最优；纯探索 → 永远学不精

### 7. Gymnasium：RL 的标准环境接口

```python
import gymnasium as gym

env = gym.make('CartPole-v1')     # 经典平衡杆
state, info = env.reset()

for step in range(1000):
    action = env.action_space.sample()          # 先随机玩
    next_state, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        state, _ = env.reset()
```

经典入门环境：
| 环境 | 状态 | 动作 | 任务 |
|------|------|------|------|
| CartPole-v1 | 4 维连续 | 2 个离散 | 杆子不倒 |
| FrozenLake-v1 | 离散格子 | 4 个离散 | 走到终点不掉冰窟 |
| MountainCar-v0 | 2 维连续 | 3 个离散 | 荡上山坡 |

### 8. 从表格到神经网络

状态空间一大（图像、连续值），Q 表存不下 → 用神经网络拟合 Q(s,a) → **这就是 DQN**（下一章）。

## 💻 实战练习

```python
# 在 FrozenLake 上实现 Q-Learning（表格法，30 行内可完成）
import gymnasium as gym
import numpy as np

env = gym.make('FrozenLake-v1', is_slippery=False)
Q = np.zeros((env.observation_space.n, env.action_space.n))
alpha, gamma, epsilon = 0.1, 0.99, 1.0

for ep in range(2000):
    s, _ = env.reset()
    done = False
    while not done:
        a = env.action_space.sample() if np.random.rand() < epsilon else Q[s].argmax()
        s2, r, term, trunc, _ = env.step(a)
        Q[s, a] += alpha * (r + gamma * Q[s2].max() - Q[s, a])
        s, done = s2, term or trunc
    epsilon = max(0.05, epsilon * 0.995)   # 衰减探索率

print("学习后的 Q 表:\n", Q)
```

## ⚠️ 常见坑

1. ε 不衰减 → 永远在随机探索，评估时看不出学会
2. γ 设成 1 且环境无限长 → 回报不收敛
3. 评估时还开着探索 → 要用纯贪心策略评估真实水平
4. 新版 Gym 的 step 返回 5 个值（terminated + truncated），老教程是 4 个（done），别抄混

## 📝 小结

- RL = 在交互中通过奖励试错学习；学的是策略 π
- 贝尔曼方程：当前价值 = 即时奖励 + 折扣未来价值
- Q-Learning + ε-greedy 是理解一切的起点
