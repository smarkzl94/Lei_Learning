# 专题-02 - Q/K/V 与自注意力

## 🎯 学习目标
- 理解 Query / Key / Value 三个向量的分工
- 能手算自注意力三步：打分 → softmax → 加权
- 理解为什么要除以 √d_k
- 会用 PyTorch 一行实现

---

## 📚 核心知识点

### 1. 三个向量的分工：图书馆类比

每个词（token）进网络前是一个向量（embedding）。自注意力给每个词派生**三个角色向量**：

| 向量 | 角色 | 图书馆类比 |
|------|------|-----------|
| **Q (Query)** | 我要找什么 | 你手里的检索词 |
| **K (Key)** | 我是什么（标签） | 每本书脊上的标签 |
| **V (Value)** | 我的实际内容 | 书里的正文 |

流程：拿你的检索词（Q）去和每本书的标签（K）比对，算出相关度；相关度高的书，把它的**正文**（V）多搬一些回来。

> 关键洞察：K 和 V 分离，意味着"我靠什么被找到"和"我被找到后提供什么"是分开学的——这比 RNN 把两者混在一个记忆球里灵活得多。

### 2. 三步计算（必背）

```python
scores  = Q @ K.T / sqrt(d_k)   # ① 打分：每个词对每对词的相关度
weights = softmax(scores)       # ② 归一化：转成和为 1 的注意力权重
output  = weights @ V           # ③ 加权：按权重汇总内容
```

### 3. 手算一遍（3 个词的迷你例）

句子 3 个词，每个词向量 2 维（真实是 512+ 维，原理一样）：

```
词向量 x:   "它"=[1,0]  "动物"=[0,1]  "累"=[1,1]
（为演示，设 W_q=W_k=W_v=单位阵，即 Q=K=V=x）
```

**① 打分**（"它"的 Q 去点积所有 K）：

```
它·它   = 1×1+0×0 = 1
它·动物 = 1×0+0×1 = 0
它·累   = 1×1+0×1 = 1
```

**② softmax 归一化**：`softmax([1, 0, 1]) ≈ [0.42, 0.16, 0.42]`

**③ 加权求和**（"它"的新表示）：

```
0.42×[1,0] + 0.16×[0,1] + 0.42×[1,1] = [0.84, 0.58]
```

"它"的新向量里混进了"动物"和"累"的信息——**这就是"回头看了一眼"的数学表达**。每个词都对自己做一遍这套流程，得到一整个新序列。

### 4. 为什么除以 √d_k

点积的数值随维度 d_k 增大而增大（维度越大，累加项越多）。score 过大 → softmax 进入饱和区 → 梯度趋近 0（回忆 04 章梯度消失）。

除以 √d_k 把分数拉回温和区间，softmax 保持在梯度健康的位置。**这不是小技巧，没有它深层 Transformer 训不动。**

### 5. 权重矩阵 W_q / W_k / W_v

上面手算用了单位阵做演示。真实网络里 Q/K/V 是**学出来的线性变换**：

```python
Q = x @ W_q    # W_q: (d_model, d_k)
K = x @ W_k
V = x @ W_v
```

训练学的就是这三个矩阵（以及后续所有层）。学好后，"它"的 Q 自然会长成"擅长匹配名词"的样子——没人告诉它语法，注意力权重里自己涌现出了指代、主谓等模式（有可视化研究证实）。

### 6. PyTorch 实现

```python
import torch, torch.nn.functional as F

def self_attention(x):                    # x: (batch, seq_len, d_model)
    d_k = x.size(-1)
    scores = x @ x.transpose(-2, -1) / d_k ** 0.5
    weights = scores.softmax(dim=-1)      # (batch, seq, seq) ← 注意力矩阵
    return weights @ x

# 生产环境一行版（自动走高效内核，支持 mask）：
out = F.scaled_dot_product_attention(Q, K, V)
```

## ⚠️ 常见坑

1. 忘记除以 √d_k → softmax 饱和，梯度消失，loss 不降
2. 注意力矩阵是 **seq×seq**——序列长度翻倍，显存 4 倍（长文本的命门）
3. softmax 的 dim 搞错：要对"每行的所有 Key"归一化，`dim=-1`

## 📝 小结

- Q 问、K 答、V 给内容；Q·K 打分、softmax 归一、加权 V 汇总
- 注意力矩阵 seq×seq：每个词对每对词的关注度，可画热力图观察
- /√d_k 防 softmax 饱和，W_q/W_k/W_v 是要学的参数
