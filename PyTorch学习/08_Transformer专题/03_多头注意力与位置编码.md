# 专题-03 - 多头注意力与位置编码

## 🎯 学习目标
- 理解为什么要"多头"而不只一个头
- 掌握多头的实现方式：切维度而非多份参数
- 理解注意力机制天生不知道词序，以及位置编码怎么补

---

## 📚 核心知识点

### 1. 一个头的问题：一次只能用一种眼光看

回顾上篇："它"通过 Q·K 关注到了"动物"。但一句话里的关系不止一种：

- **指代关系**："它" → "动物"
- **语法关系**："动物"（主语）→ "过"（谓语）
- **位置关系**：相邻词往往属于同一短语

一组 W_q/W_k/W_v 只能学出一种"相关性的定义"，逼着所有关系挤在同一张注意力矩阵里互相妥协。

### 2. 多头：h 组眼光各看各的

**多头注意力（Multi-Head Attention）**：把 d_model 维向量**切成 h 份**，每份独立做一遍自注意力，最后拼接回来：

```
d_model=512, h=8 个头
每个头拿到 512/8=64 维，独立算 Q·K、softmax、加权
8 个 64 维输出 → 拼接回 512 维 → 过一个线性层融合
```

效果：8 个头各自学出不同的关注模式。可视化研究里真的能看到——有的头专盯指代，有的盯主谓，有的盯相邻词、标点。

**参数账**：不是 8 份参数！切维度再拼回来，总参数量和单头基本一样。多头的"多"是**视角**多，不是参数多。

```python
nn.MultiheadAttention(embed_dim=512, num_heads=8, batch_first=True)
# 硬性要求：embed_dim % num_heads == 0（要切得均）
```

### 3. 注意力的盲区：不知道词序

把自注意力的计算盯紧看：每个词和**所有**词算相关度，然后加权求和——整个过程**没有任何东西告诉它谁在前谁在后**。

> "狗咬人"和"人咬狗"对纯自注意力是同一堆词的集合，打分完全相同。

CNN 靠卷积核的滑动天然带位置感，RNN 靠顺序处理天然带位置感，自注意力是**集合操作**，位置感为零。必须人工注入。

### 4. 位置编码：给每个位置发一张"身份证"

**思路**：给词向量加上一个只由位置决定的向量，让"第 3 个词"和"第 30 个词"的表示天生不同：

```
最终输入 = 词向量 + 位置向量
```

**方案一：正弦位置编码（2017 原版论文）**

```python
pe[:, 0::2] = sin(pos / 10000^(2i/d))
pe[:, 1::2] = cos(pos / 10000^(2i/d))
```

- 每个维度是一个不同频率的正弦/余弦波，位置 pos 变化时各维以不同速率变化
- 优点：不用学、对任意长度外推（训练见 128 词，推理 512 词也能编码）
- 直觉：像二进制编码的连续版，每个位置一个独特的"波形指纹"

**方案二：可学习位置嵌入（BERT/GPT 的做法）**

直接给每个位置一个可训练向量，跟着网络一起学。简单有效，缺点：最大长度被训练时的设定锁死。

**现代变体**（了解）：RoPE 旋转位置编码（Llama 系列）、ALiBi——把位置信息揉进 Q·K 的计算里而非加在输入上，长文本外推更好。

## ⚠️ 常见坑

1. `embed_dim % num_heads != 0` → 直接报错，选头数先看整除
2. 忘了加位置编码 → 模型把句子当词袋，语序信息全丢
3. 用可学习位置嵌入但推理序列超过训练长度 → 位置越界报错

## 💬 课堂问答沉淀

**Q1：8 个头、embed_dim=512，每个头的 Q/K/V 是多少维？多头比单头参数多吗？**
每个头分到 512÷8 = **64 维**。参数量与单头**基本持平**：单头是 512×512 的大投影矩阵，多头是 8 个 512×64，拼起来仍是 512×512。多头不是"参数更多"，而是"同样的参数切 8 份，每份在小空间里学一种专门的眼光"。

**Q2：打乱词序，自注意力输出会变吗？**
不变（严格说是**排列等变**：输入打乱，输出只是跟着同样打乱，内容不变）。纯自注意力只看"有哪些词"，不看"词在哪"——这正是必须加位置编码的原因。
practice08 实验验证：「人咬狗」vs「狗咬人」同样的词顺序相反，不加位置编码时「人」的输出完全相同（`torch.allclose` 为 True）；加正弦位置编码后两处输出最大差异 = 0.743，词序信息进模型了。

**Q3：practice08 的 8 头热力图为什么各头都"很分散"（平均最大权重仅 0.24~0.30）？**
那是**随机初始化**的必然状态——刚出生的头没有分工，大家广撒网。训练好的 Transformer 里部分头专注度会到 0.8+，分化出盯主语、盯标点、盯指代等专门角色。看热力图要意识到这是"训练前"快照。

## 📝 小结

- 多头 = 把维度切成 h 份独立做注意力，多视角、参数不翻倍
- 自注意力是集合操作，天生无词序 → 必须注入位置编码
- 正弦编码（免学、可外推）vs 可学习嵌入（简单、长度锁死）
