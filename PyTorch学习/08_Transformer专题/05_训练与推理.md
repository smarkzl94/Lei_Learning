# 专题-05 - 训练与推理

## 🎯 学习目标
- 理解 causal mask：为什么不能看未来的词
- 理解 teacher forcing：训练时如何并行
- 理解推理为什么只能逐词生成（自回归）
- 了解 beam search 和温度采样

---

## 📚 核心知识点

### 1. 生成任务的规矩：不许偷看答案

文本生成是"给定前面的词，预测下一个词"：

```
输入："我 爱 深"  →  预测："度"
输入："我 爱 深 度"  →  预测："学"
```

问题：自注意力是每个词看**所有**词——预测"度"时如果看到了后面的"学 习"，等于考试偷看答案，模型什么真本事都学不到。

### 2. Causal Mask：上三角封禁

解法：在注意力打分矩阵上盖一个**下三角掩码**——每个词只被允许看自己及之前的词，未来位置的 score 设成 -∞（softmax 后权重为 0）：

```
注意力矩阵（4 个词）     ■=允许看   □=封禁(-∞)
       我  爱  深  度
  我 [ ■   □   □   □ ]
  爱 [ ■   ■   □   □ ]
  深 [ ■   ■   ■   □ ]
  度 [ ■   ■   ■   ■ ]
```

```python
seq = 4
mask = torch.triu(torch.full((seq, seq), float('-inf')), diagonal=1)
# 上三角(不含对角线) = -inf
out = F.scaled_dot_product_attention(Q, K, V, attn_mask=mask)
```

这就是 **causal mask（因果掩码）**，GPT 类模型的标配。BERT 那种"理解"任务不用它（完形填空允许看全句）。

### 3. Teacher Forcing：训练时并行的小魔法

RNN 训练慢是因为逐步依赖。Transformer 训练时用 **teacher forcing** 实现并行：

把**完整正确句子**一次性喂进去，配合 causal mask：

```
输入（右移一位）：<开始> 我 爱 深 度
目标（原句）：     我   爱 深 度 学
```

每个位置都在预测"下一个词"，mask 保证它只看得到前面的——**4 个预测任务一次并行算完**，互不干扰。这就是 Transformer 训练比 RNN 快几个数量级的原因之一。

> "右移一位"是标准操作：第 i 个位置的输入是第 i-1 个正确的词（老师给的），所以叫 teacher forcing。

### 4. 推理：只能逐词生成（自回归）

推理时没有正确答案可喂，只能：

```
喂 "<开始>"        → 模型吐出 "我"
喂 "<开始> 我"     → 模型吐出 "爱"
喂 "<开始> 我 爱"  → 模型吐出 "深"
...直到生成 <结束>
```

每生成一个词都要完整跑一遍网络——**这叫自回归（autoregressive）**。所以 ChatGPT 回答是一个字一个字往外蹦的，长回复的等待时间正比于词数。

> 工程上靠 KV-Cache 加速：已算过的 K/V 缓存复用，每步只算新词的注意力。

### 5. 生成策略：选哪个词

模型每步输出的是**词表上每个词的概率分布**（几万维的 softmax），选词方式决定生成风格：

| 策略 | 做法 | 效果 |
|------|------|------|
| 贪心 | 每步选概率最高的 | 稳定但复读机、无聊 |
| 温度采样 | 按概率随机抽，温度 T 调分布锐度 | T<1 保守，T>1 发散有创意 |
| Top-k / Top-p | 只在概率前 k 个/累计前 p% 里抽 | 质量与多样性折中，主流 |
| Beam search | 同时保留 b 条候选路径再择优 | 翻译类任务常用，开放式生成偏保守 |

你调 ChatGPT 的 temperature 参数就是在玩第二行。

---

## ⚠️ 常见坑

1. 训练忘了 causal mask → 训练 loss 极低、生成全崩（泄漏未来信息）
2. mask 用 0/1 而不是 0/-∞ → 封禁位置仍有权重，泄漏
3. 忘了输入要右移一位 → 模型直接复制输入
4. 以为推理也能并行——自回归是生成式模型的本质约束，只能优化（KV-Cache），不能消除

---

## 📝 小结

- Causal mask = 上三角 -∞，保证预测下一个词时看不到未来
- Teacher forcing = 正确句子整体喂入 + 右移 + mask，训练全并行
- 推理是自回归逐词生成，KV-Cache 是主要加速手段
- 采样策略（温度/top-p）控制生成的保守与发散
