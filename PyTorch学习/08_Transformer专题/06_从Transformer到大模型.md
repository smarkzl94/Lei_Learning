## 📚 核心知识点

### 1. 一棵树两个叉

2017 年原版 Transformer 是 encoder + decoder（为翻译设计）。2018 年起分成两大流派，各自只取一半：

| | BERT 路线（只要 encoder） | GPT 路线（只要 decoder） |
|---|---|---|
| 代表 | BERT、RoBERTa | GPT-1/2/3/4、Llama、Qwen |
| 注意力 | 双向（看全句） | 单向 + causal mask |
| 训练任务 | 完形填空（遮住词猜） | 预测下一个词 |
| 擅长 | 理解：分类、抽取、检索 | 生成：对话、写作、代码 |
| 现状 | 细分场景仍活跃 | **当下绝对主流** |

为什么 decoder 路线赢了？"预测下一个词"这个任务**不需要任何人工标注**——全互联网的文本天然就是训练数据，规模可以无限堆。规模上来后，生成模型顺带也学会了理解（融会贯通）。

### 2. 预训练 + 微调：现代深度学习的工作方式

```
阶段一：预训练（Pre-training）
  互联网海量文本 + 预测下一个词
  → 得到"基座模型"：懂语言、有常识，但不会好好回答问题
  成本：几千张 GPU 几个月，只有大公司玩得起

阶段二：微调（Fine-tuning）
  少量高质量数据，教基座模型具体技能
  → 指令微调（SFT）：学会"听懂指令、按格式回答"
  → RLHF：学会"回答得更讨人喜欢、更安全"
  成本：几张卡几小时到几天，个人也能做（LoRA 等参数高效微调）
```

你平时"下载一个开源模型微调一下"，做的就是阶段二。01 章说的"深度学习自动学特征"，在大模型时代变成了"预训练模型已经学好了通用特征，你只教它你行业的规矩"。

### 3. RLHF：当强化学习遇上大模型

回忆 03 章 RLHF 那一行——现在把它展开。SFT 之后模型会回答了，但"好回答"和"更好的回答"之间没有标准答案，只有**人类偏好**。这正是强化学习的主场：

```
① 收集偏好：让模型对同一问题生成多个回答，人标注哪个更好
② 训练奖励模型：用偏好数据训一个"打分器"（预测人会选哪个）
③ 强化学习优化：PPO 算法调整模型，让奖励模型打的分越来越高
   （同时用 KL 散度约束：别离原模型太远，防止刷分走火入魔）
```

对照 03 章五角色：

| 角色 | RLHF 中 |
|------|---------|
| 智能体 | 语言模型（策略 = 下一个词选谁） |
| 环境 | 对话上下文 |
| 动作 | 生成一个词 |
| 奖励 | 奖励模型的打分 |
| 算法 | **PPO**（07 章会手写） |

ChatGPT 的"有用、无害、诚实"主要就是这一步调出来的。

## 💻 实战练习（拓展）

用 Hugging Face 三行代码加载一个开源小模型，体验"预训练+微调"：

```python
from transformers import pipeline
clf = pipeline("sentiment-analysis")         # 情感分析（BERT 系）
print(clf("这堂课讲得真清楚"))
gen = pipeline("text-generation", model="Qwen/Qwen2.5-0.5B")  # 生成（GPT 系）
print(gen("深度学习是", max_new_tokens=30))
```

## 📝 小结

- BERT 取 encoder 做理解，GPT 取 decoder 做生成；"预测下一个词"赢了因为数据无限
- 现代工作流：大公司预训练基座 → 个人微调（SFT / LoRA）
- RLHF = 用人类偏好训奖励模型，再用 PPO 优化语言模型——强化学习最出圈的应用
- 专题到此通关：注意力 → 多头/位置 → 架构 → 训练推理 → 大模型谱系
- 回主线：05-1 RNN/LSTM 值得回头补，07 强化学习会把 PPO 从黑盒变成你能写的代码
