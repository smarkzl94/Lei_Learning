# Transformer 专题学习路线

主线 05 章的「Transformer 基础」是压缩版笔记，本专题是它的深入展开：
把一个大黑盒拆成六块，每块配直觉、手算、PyTorch 代码和检验题。

## 先修要求

开始前确认这些都学过了（都在主线里）：

- ✅ 00 理论基础：前向 / 损失 / 反向传播 / 梯度下降
- ✅ 02 神经网络基础：nn.Module、训练循环
- ✅ 04 CNN 基础：**残差连接**（Transformer 每个子层都用它）
- ⬜ 05-1 RNN 与 LSTM（第 01 篇会对比着讲，没学也不影响，但建议先过一遍）

## 六篇路线

| 篇 | 主题 | 核心问题 | 预计 |
|---|------|----------|------|
| 01 | 为什么需要注意力 | RNN 哪里不行，注意力解决了什么 | 20 min |
| 02 | Q/K/V 与自注意力 | 三个向量是什么，打分怎么算 | 40 min |
| 03 | 多头注意力与位置编码 | 为什么要多个头，顺序信息从哪来 | 30 min |
| 04 | 完整架构拆解 | 一个 block 有哪些零件，怎么堆叠 | 40 min |
| 05 | 训练与推理 | teacher forcing、mask、逐词生成 | 40 min |
| 06 | 从 Transformer 到大模型 | BERT/GPT 谱系、RLHF 衔接 07 章 | 20 min |

每篇结构沿用主线模板：🎯 学习目标 → 📚 核心知识点（直觉→手算→代码）→ 💻 实战练习 → ⚠️ 常见坑 → 📝 小结。

## 配套实操

每篇的 💻 练习对应 `practice/` 里的一个脚本：

| 篇 | 脚本 | 内容 |
|---|------|------|
| 02 | practice07.py | 手算 + PyTorch 复现一次自注意力，画注意力热力图 |
| 03 | practice08.py | 多头注意力可视化：不同头真的关注不同模式 |
| 04 | practice09.py | 用 nn.TransformerEncoder 做文本/序列分类 |
| 05 | practice10.py | 迷你版逐词生成，亲眼看 mask 的作用 |

## 检验里程碑

- 过完 02：能不看笔记写出自注意力三步公式（打分→softmax→加权）
- 过完 04：能画出完整 encoder block 的数据流（含两条残差边）
- 过完 06：能向人解释"GPT 和 BERT 都是 Transformer，差别在哪"

## 建议节奏

每天 1 篇，一周通关。02 和 04 是重头戏，值得各花两倍时间；
05 的 mask 概念最容易绕晕，卡住就回来看图。
