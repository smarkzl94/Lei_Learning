# ROS + C++ 系统性学习框架

> **目标**：从零开始，系统掌握 C++ 编程和 ROS 机器人操作系统，能够独立开发机器人应用。
>
> **学习理念**：不追求速度，逐个知识点扎实掌握，学一个归档一个。
>
> **目录结构**：本框架分为两个独立但关联的学习课题 —— **C++ 编程基础** 和 **ROS 机器人操作系统**。

---

## 🛠️ 环境准备

### C++ 开发环境
- **编译器**：GCC 9+ / Clang
- **编辑器**：VS Code + C++ 插件 / CLion
- **构建工具**：CMake（ROS 必备）

### ROS 环境
- **操作系统**：Ubuntu 20.04 / 22.04
- **ROS 版本**：Noetic (ROS1) / Humble (ROS2)
- **虚拟机方案**：VMware/VirtualBox + Ubuntu（Windows 用户）

## ✅ 如何使用本框架

1. **按顺序学习**：每个阶段有前置依赖，建议按顺序完成
2. **逐个归档**：学完一个知识点，确认理解后再进入下一个
3. **边学边练**：每个知识点至少写一段代码验证
4. **记录进度**：用 `学习进度.md` 勾选已完成项
5. **项目驱动**：C++ 学到面向对象后，可用 ROS 项目串起知识点
