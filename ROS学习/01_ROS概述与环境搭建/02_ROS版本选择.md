# 02 - ROS 版本选择

## 🎯 学习目标
- 了解 ROS1 和 ROS2 的区别
- 能够根据自身需求选择合适的版本
- 了解 ROS 与其他机器人框架的对比

---

## 📚 核心知识点

### 1. ROS1 vs ROS2

| 特性 | ROS1 | ROS2 |
|------|------|------|
| **中间件** | 自定义 TCPROS/UDPROS | DDS (Data Distribution Service) |
| **实时性** | 不支持硬实时 | 支持实时（配合 RTOS） |
| **嵌入式** | 不支持 | 支持微控制器 |
| **安全性** | 无内置安全 | 支持加密、认证、访问控制 |
| **多机器人** | 需要额外配置 | 原生支持 |
| **构建工具** | catkin | colcon |
| **Python 版本** | Python 2/3 | Python 3 |
| **生命周期** | 已停止新功能开发 | 活跃开发中 |

### 2. ROS1 详细版本

| 版本 | Ubuntu | 发布日期 | 停止维护 |
|------|--------|----------|----------|
| Kinetic | 16.04 | 2016.05 | 2021.04 |
| Melodic | 18.04 | 2018.05 | 2023.04 |
| **Noetic** | **20.04** | **2020.05** | **2025.04** |

### 3. ROS2 详细版本

| 版本 | Ubuntu | 发布日期 | 维护状态 |
|------|--------|----------|----------|
| Foxy | 20.04 | 2020.06 | 2023.06 |
| Galactic | 20.04 | 2021.05 | 2022.12 |
| **Humble** | **22.04** | **2022.05** | **2027.05** |
| Iron | 22.04 | 2023.05 | 2024.11 |
| Jazzy | 24.04 | 2024.05 | 2029.05 |

### 4. 选择建议

**选 ROS1 (Noetic) 如果：**
- 你是初学者，需要大量中文教程
- 你要使用的传感器/算法只有 ROS1 版本
- 项目短期交付，不需要长期维护
- 你的硬件是 x86 工控机，不强调实时性

**选 ROS2 (Humble) 如果：**
- 你有一定 ROS1 基础，想学习新技术
- 项目需要长期维护
- 需要部署到嵌入式设备（如树莓派、Jetson）
- 有多机器人协同需求
- 需要工业级安全认证

### 5. ROS 与其他框架对比

| 框架 | 特点 | 适用场景 |
|------|------|----------|
| **ROS** | 生态最完善 | 研究、教育、 prototyping |
| **MoveIt** | 运动规划 | 机械臂路径规划 |
| **Navigation2 (ROS2)** | 导航 | 移动机器人自主导航 |
| **Gazebo** | 物理仿真 | 算法验证 |
| **Isaac Sim (NVIDIA)** | GPU 加速仿真 | 深度学习 + 机器人 |
| **Webots** | 教育仿真 | 教学 |
| **PyBullet** | 轻量仿真 | 强化学习 |

## ✏️ 练习任务

### 练习 1：调研周边资源
查看你手头的硬件（或计划购买的硬件）是否支持你选的 ROS 版本：
- 激光雷达驱动
- 摄像头驱动


### 练习 3：社区调研
在 ROS Answers 上搜索你感兴趣的机器人项目，看它们用的是 ROS1 还是 ROS2。

## ❓ 常见问题

**Q: ROS1 会彻底消失吗？**
A: 不会马上消失。Noetic 维护到 2025 年，之后社区也会继续维护。但新项目建议用 ROS2。

**Q: 可以同时安装 ROS1 和 ROS2 吗？**
A: 可以，通过不同的工作空间和 `source` 不同的 setup.bash 来切换。

**Q: 从 ROS1 迁移到 ROS2 困难吗？**
A: 概念相似但实现差异大。ROS2 提供了 `ros1_bridge` 用于两者通信，可以逐步迁移。
