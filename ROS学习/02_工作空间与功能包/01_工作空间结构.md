## 📚 核心知识点

### 1. 工作空间（Workspace）

工作空间是 ROS 项目的根目录，包含所有代码、编译结果和配置文件。

```
~/ros2_ws/
├── build/              # 编译中间文件
├── install/            # 安装目录（ros2 run 从这里找可执行文件）
│   ├── setup.bash
│   └── [包名...]
├── log/                # 编译日志
└── src/                # 源代码（唯一要手动碰的目录）
    └── [功能包...]
```

### 2. 创建和编译工作空间

```bash
# 创建
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws

# 编译
colcon build                                # 基本编译
colcon build --packages-select my_package   # 只编译指定包
colcon build --symlink-install              # 符号链接安装（开发时推荐）
colcon test                                 # 运行测试

# 配置环境（每个新终端都要 source，写进 .bashrc 可偷懒）
source ~/ros2_ws/install/setup.bash
```

### 3. Overlay 工作空间

可以叠加多个工作空间，后面的覆盖前面的：

```bash
# 先加载系统 ROS
source /opt/ros/humble/setup.bash

# 再加载自己的工作空间（overlay）
source ~/ros2_ws/install/setup.bash

# 此时 ~/ros2_ws 的包会覆盖系统同名包
echo $AMENT_PREFIX_PATH
# 输出: /home/user/ros2_ws/install:/opt/ros/humble
```

### 4. 环境变量

| 变量 | 说明 |
|------|------|
| `AMENT_PREFIX_PATH` | 包搜索路径（ROS2 核心，替代 ROS1 的 ROS_PACKAGE_PATH） |
| `ROS_DISTRO` | ROS 版本（应为 humble） |
| `CMAKE_PREFIX_PATH` | CMake 查找路径 |
| `ROS_LOCALHOST_ONLY` | =1 时只本机通信（单机调试加速） |

## 💻 动手实验

```bash
# 创建新工作空间
mkdir -p ~/test_ws/src
cd ~/test_ws

# 编译空工作空间
colcon build

# 查看生成的文件
ls build/
ls install/

# 加载环境
source install/setup.bash

# 查看包路径
echo $AMENT_PREFIX_PATH
```

## ❓ 常见问题

**Q: 为什么修改了代码但运行结果没变？**
A: 检查：1) 是否重新 `colcon build`；2) 是否 `source install/setup.bash`（注意 ros2 run 跑的是 install/ 里的产物，不是 src/）。
