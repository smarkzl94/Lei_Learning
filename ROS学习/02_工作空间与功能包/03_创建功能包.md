## 📚 核心知识点

### 1. 功能包（Package）

功能包是 ROS 软件组织的基本单元，包含节点、库、配置文件等。

```
my_package/
├── package.xml          # 包元信息
├── CMakeLists.txt       # 构建配置（C++ 包）
│   或 setup.py          # 构建配置（Python 包）
├── src/                 # 源代码
│   └── my_node.cpp
├── include/             # 头文件
│   └── my_package/
│       └── my_header.hpp
├── scripts/             # Python 脚本（可执行）
│   └── my_script.py
├── launch/              # 启动文件
│   └── my_launch.launch
├── config/              # 配置文件
│   └── params.yaml
├── msg/                 # 自定义消息
│   └── MyMessage.msg
├── srv/                 # 自定义服务
│   └── MyService.srv
├── action/              # 自定义动作
│   └── MyAction.action
├── urdf/                # 机器人描述
│   └── robot.urdf
└── worlds/              # Gazebo 世界文件
    └── my_world.world
```

### 2. 创建功能包

```bash
cd ~/ros2_ws/src

# 使用 ros2 pkg create
ros2 pkg create --build-type ament_cmake my_cpp_pkg
ros2 pkg create --build-type ament_python my_py_pkg

# 常用选项
ros2 pkg create my_pkg \
    --build-type ament_cmake \
    --dependencies rclcpp std_msgs \
    --node-name my_node \
    --license MIT
```

### 3. 第一个 C++ 节点（ROS2）

#### 代码
```cpp
// src/hello_ros.cpp
#include <rclcpp/rclcpp.hpp>

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    
    auto node = rclcpp::Node::make_shared("hello_ros_node");
    
    rclcpp::Rate rate(1);
    
    while (rclcpp::ok()) {
        RCLCPP_INFO(node->get_logger(), "Hello ROS2!");
        rate.sleep();
    }
    
    rclcpp::shutdown();
    return 0;
}
```

#### 编译和运行
```bash
cd ~/ros2_ws
colcon build --packages-select my_pkg
source install/setup.bash
ros2 run my_pkg hello_ros
```

### 4. 第一个 Python 节点

```python
#!/usr/bin/env python3
# scripts/hello_ros.py

import rclpy
from rclpy.node import Node

class HelloNode(Node):
    def __init__(self):
        super().__init__('hello_ros_py')
        self.timer = self.create_timer(1.0, self.timer_callback)

    def timer_callback(self):
        self.get_logger().info("Hello from Python!")

def main():
    rclpy.init()
    rclpy.spin(HelloNode())
    rclpy.shutdown()
```

## ❓ 常见问题

**Q: `ros2 run` 找不到包？**
A: 1) 检查是否 source 了 `install/setup.bash`（每个新终端都要）；2) 检查包是否在正确的 src 目录；3) 重新 `colcon build`。

**Q: 节点名冲突怎么办？**
A: 启动时加 `--ros-args -r __node:=新名字` 重命名，或在 launch 文件中 remap。

**Q: 如何调试 ROS2 节点？**
```bash
# GDB 调试
ros2 run --prefix 'gdb -ex run --args' my_pkg my_node

# Valgrind 内存检查
ros2 run --prefix 'valgrind' my_pkg my_node
```
