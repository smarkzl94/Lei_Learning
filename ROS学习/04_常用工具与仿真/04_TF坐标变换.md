## 📚 核心知识点

### 1. TF 简介

TF (Transform) 是 ROS 中的坐标变换系统：
- 维护机器人各部件之间的坐标关系
- 形成一棵树结构（`map` → `odom` → `base_link` → `sensor_link`）
- 支持时间相关的变换查询

```
map (世界坐标系)
  └── odom (里程计坐标系)
        └── base_link (机器人本体)
              ├── laser_link (激光雷达)
              ├── camera_link (摄像头)
              └── wheel_left_link (左轮)
```

### 4. 发布动态 TF（tf2_ros，C++）

```cpp
#include <rclcpp/rclcpp.hpp>
#include <tf2_ros/transform_broadcaster.h>
#include <geometry_msgs/msg/transform_stamped.hpp>
#include <tf2/LinearMath/Quaternion.hpp>

class TfBroadcaster : public rclcpp::Node {
public:
    TfBroadcaster() : Node("tf_broadcaster") {
        broadcaster_ = std::make_unique<tf2_ros::TransformBroadcaster>(*this);
        timer_ = create_wall_timer(std::chrono::milliseconds(10),  // 100 Hz
            std::bind(&TfBroadcaster::broadcast, this));
    }

private:
    void broadcast() {
        geometry_msgs::msg::TransformStamped t;
        t.header.stamp = now();
        t.header.frame_id = "base_link";
        t.child_frame_id = "laser_link";
        t.transform.translation.x = 0.5;
        t.transform.translation.y = 0.0;
        t.transform.translation.z = 0.3;
        t.transform.rotation.x = 0.0;
        t.transform.rotation.y = 0.0;
        t.transform.rotation.z = 0.0;
        t.transform.rotation.w = 1.0;

        broadcaster_->sendTransform(t);
    }

    std::unique_ptr<tf2_ros::TransformBroadcaster> broadcaster_;
    rclcpp::TimerBase::SharedPtr timer_;
};
```

### 5. 监听 TF 变换

```cpp
#include <rclcpp/rclcpp.hpp>
#include <tf2_ros/transform_listener.h>
#include <tf2_ros/buffer.h>

class TfListener : public rclcpp::Node {
public:
    TfListener() : Node("tf_listener") {
        buffer_ = std::make_unique<tf2_ros::Buffer>(get_clock());
        listener_ = std::make_shared<tf2_ros::TransformListener>(*buffer_);
        timer_ = create_wall_timer(std::chrono::milliseconds(100),
            std::bind(&TfListener::lookup, this));
    }

private:
    void lookup() {
        try {
            // 参数：目标坐标系、源坐标系、时间（TimePointZero = 最新可用）
            auto t = buffer_->lookupTransform("base_link", "laser_link",
                                              tf2::TimePointZero);
            RCLCPP_INFO(get_logger(), "Translation: (%.2f, %.2f, %.2f)",
                t.transform.translation.x,
                t.transform.translation.y,
                t.transform.translation.z);
        } catch (const tf2::TransformException& ex) {
            RCLCPP_ERROR(get_logger(), "%s", ex.what());
        }
    }

    std::unique_ptr<tf2_ros::Buffer> buffer_;
    std::shared_ptr<tf2_ros::TransformListener> listener_;
    rclcpp::TimerBase::SharedPtr timer_;
};
```

### 6. 坐标变换计算（把点从一个坐标系变到另一个）

```cpp
// 将点从 laser 坐标系转换到 base_link
geometry_msgs::msg::PointStamped laser_point;
laser_point.header.frame_id = "laser_link";
laser_point.header.stamp = now();
laser_point.point.x = 1.0;
laser_point.point.y = 0.0;
laser_point.point.z = 0.0;

try {
    auto base_point = buffer_->transform(laser_point, "base_link");
} catch (const tf2::TransformException& ex) {
    RCLCPP_ERROR(get_logger(), "%s", ex.what());
}
```

## ❓ 常见问题

**Q: TF 树为什么必须是树结构？**
A: 确保任意两个坐标系之间有唯一变换路径。如果有环，变换不唯一。

**Q: `tf2::TimePointZero` 和 `now()` 的区别？**
A: `TimePointZero` 获取**最新可用**变换（最常用）；`now()` 获取当前时刻的变换（可能因延迟查询失败，需配超时重试）。

**Q: TF 发布频率设多少合适？**
A: 通常 50-100Hz。静态变换不要自己循环发，用 `static_transform_publisher`（自动走 `/tf_static`，只发一次）。
