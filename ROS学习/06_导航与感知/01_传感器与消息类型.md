## 📚 核心知识点

### 1. 常见传感器

| 传感器 | 作用 | ROS 消息类型 |
|--------|------|-------------|
| 激光雷达 (LiDAR) | 测距、建图 | `sensor_msgs/LaserScan` |
| 摄像头 | 视觉感知 | `sensor_msgs/Image`, `sensor_msgs/CameraInfo` |
| 深度相机 | 3D 视觉 | `sensor_msgs/PointCloud2` |
| IMU | 姿态、加速度 | `sensor_msgs/Imu` |
| 里程计 | 位置估计 | `nav_msgs/Odometry` |
| GPS | 全局定位 | `sensor_msgs/NavSatFix` |
| 超声波 | 近距离测距 | `sensor_msgs/Range` |
| 编码器 | 轮速测量 | 自定义或 `std_msgs/Float64` |

### 2. LaserScan 消息

```cpp
# sensor_msgs/LaserScan
std_msgs/Header header
float32 angle_min        # 扫描起始角度
float32 angle_max        # 扫描结束角度
float32 angle_increment  # 角度分辨率
float32 time_increment   # 每点测量时间间隔
float32 scan_time        # 整帧扫描时间
float32 range_min        # 最小有效距离
float32 range_max        # 最大有效距离
float32[] ranges         # 距离数组（米）
float32[] intensities    # 强度数组（可选）
```

```cpp
// C++ 处理示例
void laserCallback(const sensor_msgs::LaserScan::ConstPtr& msg) {
    float min_dist = msg->range_max;
    int min_index = 0;
    
    for (size_t i = 0; i < msg->ranges.size(); ++i) {
        float range = msg->ranges[i];
        // 过滤无效值
        if (range > msg->range_min && range < msg->range_max) {
            if (range < min_dist) {
                min_dist = range;
                min_index = i;
            }
        }
    }
    
    float angle = msg->angle_min + min_index * msg->angle_increment;
    ROS_INFO("Closest obstacle: %.2f m at %.2f rad", min_dist, angle);
}
```

### 4. Image 消息

```cpp
#include <cv_bridge/cv_bridge.h>
#include <sensor_msgs/image_encodings.h>
#include <opencv2/imgproc/imgproc.hpp>

void imageCallback(const sensor_msgs::Image::ConstPtr& msg) {
    try {
        cv_bridge::CvImagePtr cv_ptr = cv_bridge::toCvCopy(
            msg, sensor_msgs::image_encodings::BGR8);
        
        // OpenCV 处理
        cv::Mat gray;
        cv::cvtColor(cv_ptr->image, gray, cv::COLOR_BGR2GRAY);
        
        // 显示
        cv::imshow("Image", cv_ptr->image);
        cv::waitKey(1);
    }
    catch (cv_bridge::Exception& e) {
        ROS_ERROR("cv_bridge exception: %s", e.what());
    }
}
```

### 5. Odometry 消息

```cpp
// nav_msgs/Odometry
std_msgs/Header header
string child_frame_id
geometry_msgs/PoseWithCovariance pose
geometry_msgs/TwistWithCovariance twist
```

```cpp
void odomCallback(const nav_msgs::Odometry::ConstPtr& msg) {
    double x = msg->pose.pose.position.x;
    double y = msg->pose.pose.position.y;
    
    tf::Quaternion q(
        msg->pose.pose.orientation.x,
        msg->pose.pose.orientation.y,
        msg->pose.pose.orientation.z,
        msg->pose.pose.orientation.w);
    tf::Matrix3x3 m(q);
    double roll, pitch, yaw;
    m.getRPY(roll, pitch, yaw);
    
    ROS_INFO("Position: (%.2f, %.2f), Yaw: %.2f", x, y, yaw);
}
```

## ❓ 常见问题

**Q: 点云数据太大，怎么优化？**
A: 使用体素网格（voxel grid）降采样，或只处理感兴趣区域（ROI）。

**Q: 图像消息和 OpenCV Mat 怎么转换？**
A: 使用 `cv_bridge` 库，注意编码格式（BGR8、MONO8、RGB8 等）。

**Q: 里程计漂移怎么办？**
A: 这是 wheel odometry 的固有问题。可以用 IMU 融合、激光里程计（laser odometry）或视觉里程计（visual odometry）来改善。
