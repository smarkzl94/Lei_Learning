# 02 - 移动机器人仿真导航

## 🎯 项目目标
在 Gazebo 中实现完整的移动机器人自主导航。

---

## 📋 项目步骤

### 第一步：机器人建模

创建完整的移动机器人 URDF/Xacro：
- 底盘 + 轮子
- 激光雷达
- 摄像头（可选）

### 第二步：Gazebo 仿真

配置仿真环境：
- 差速驱动插件
- 激光雷达插件
- 自定义世界

### 第三步：SLAM 建图

```bash
# 启动仿真
ros2 launch my_robot gazebo.launch.py

# 建图（slam_toolbox）
ros2 launch my_robot slam.launch.py

# 保存地图
ros2 run nav2_map_server map_saver_cli -f my_map
```

### 第四步：导航配置

配置 Nav2（nav2_params.yaml）：
- 代价地图参数（controller/planner server 内嵌）
- 控制器（FollowPath / DWB）与规划器（GridBased）
- 恢复行为（behavior_server）

### 第五步：测试和调优

```bash
# 启动导航（nav2 bringup = 地图服务 + AMCL 定位 + 导航栈）
ros2 launch nav2_bringup bringup_launch.py map:=my_map.yaml

# RViz 中用 "Nav2 Goal" 设置目标点
```

## 📝 参考 Launch 文件（Python，Nav2 组装）

```python
# launch/navigation.launch.py
from launch import LaunchDescription
from launch.actions import IncludeLaunchDescription, DeclareLaunchArgument
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import LaunchConfiguration, PathJoinSubstitution
from launch_ros.substitutions import FindPackageShare

def generate_launch_description():
    map_arg = DeclareLaunchArgument(
        'map', default_value=PathJoinSubstitution(
            [FindPackageShare('my_robot'), 'maps', 'my_map.yaml']))

    # nav2 bringup = map_server + amcl + bt_navigator + planner/controller...
    nav2 = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(PathJoinSubstitution([
            FindPackageShare('nav2_bringup'), 'launch', 'bringup_launch.py'])),
        launch_arguments={
            'map': LaunchConfiguration('map'),
            'params_file': PathJoinSubstitution(
                [FindPackageShare('my_robot'), 'config', 'nav2_params.yaml']),
        }.items())

    return LaunchDescription([map_arg, nav2])
```
