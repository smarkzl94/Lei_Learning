# 02 - 移动机器人仿真导航

## 🎯 项目目标
在 Gazebo 中实现完整的移动机器人自主导航。

---

## 📋 项目步骤

### 第一步：机器人建模

创建完整的移动机器人 URDF/Xacro：
- 底盘 + 轮子
- 激光雷达
- 摄像头（可选）

### 第二步：Gazebo 仿真

配置仿真环境：
- 差速驱动插件
- 激光雷达插件
- 自定义世界

### 第三步：SLAM 建图

```bash
# 启动仿真
roslaunch my_robot gazebo.launch

# 建图
roslaunch my_robot slam.launch

# 保存地图
rosrun map_server map_saver -f my_map
```

### 第四步：导航配置

配置 move_base：
- 代价地图参数
- 局部/全局规划器
- 恢复行为

### 第五步：测试和调优

```bash
# 启动导航
roslaunch my_robot navigation.launch map:=my_map.yaml

# RViz 中设置目标点
```

---

## 📝 参考 Launch 文件

```xml
<!-- launch/navigation.launch -->
<launch>
  <!-- 参数 -->
  <arg name="map" default="$(find my_robot)/maps/my_map.yaml"/>
  <arg name="open_rviz" default="true"/>
  
  <!-- 地图服务器 -->
  <node pkg="map_server" type="map_server" name="map_server" 
        args="$(arg map)"/>
  
  <!-- AMCL 定位 -->
  <include file="$(find my_robot)/launch/amcl.launch"/>
  
  <!-- Move Base -->
  <include file="$(find my_robot)/launch/move_base.launch"/>
  
  <!-- RViz -->
  <group if="$(arg open_rviz)">
    <node pkg="rviz" type="rviz" name="rviz" 
          args="-d $(find my_robot)/config/navigation.rviz"/>
  </group>
</launch>
```
