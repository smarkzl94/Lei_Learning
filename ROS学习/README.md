# ROS 系统性学习计划

> **目标**：从零开始系统掌握 ROS（Robot Operating System），能够独立搭建机器人仿真环境、开发节点、实现导航与感知功能。
>
> **学习理念**：逐个知识点扎实推进，理解一个再进入下一个，不追求速度。
> **前置要求**：具备 Linux 基础操作能力和 C++ 或 Python 基础

## 🛠️ 环境准备

### 系统要求
| 项目 | 推荐配置 |
|------|----------|
| 操作系统 | Ubuntu 20.04 / 22.04 |
| ROS 版本 | Noetic (20.04) / Humble (22.04) |
| 内存 | 8GB+ |
| 硬盘 | 50GB+ |

### Windows 用户方案
1. **虚拟机**：VMware Workstation / VirtualBox + Ubuntu
2. **WSL2**：Windows Subsystem for Linux（Gazebo 可能有兼容问题）
3. **双系统**：最推荐的方案

### 安装验证
```bash
# 检查 ROS 安装
rosversion -d

# 运行小海龟测试
roscore
rosrun turtlesim turtlesim_node
rosrun turtlesim turtle_teleop_key
```
