## 📚 核心知识点

### 1. 运算符分类

#### 算术运算符
| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b`（整数除法会截断） |
| `%` | 取模 | `a % b`（仅整数） |
| `++` | 自增 | `++a`（前置）/ `a++`（后置） |
| `--` | 自减 | `--a`（前置）/ `a--`（后置） |

#### 关系运算符
```cpp
a == b   // 等于
a != b   // 不等于
a > b    // 大于
a < b    // 小于
a >= b   // 大于等于
a <= b   // 小于等于
```

#### 逻辑运算符
```cpp
a && b   // 逻辑与（短路求值）
a || b   // 逻辑或（短路求值）
!a       // 逻辑非
```

#### 位运算符
```cpp
a & b    // 按位与
a | b    // 按位或
a ^ b    // 按位异或
~a       // 按位取反
a << 2   // 左移
a >> 2   // 右移
```

#### 赋值运算符
```cpp
a = b;       // 赋值
a += b;      // 等价于 a = a + b
a -= b;      // 等价于 a = a - b
a *= b;
a /= b;
a %= b;
a &= b;      // 位运算复合赋值
a |= b;
a ^= b;
a <<= 2;
a >>= 2;
```

#### 三目运算符
```cpp
int max = (a > b) ? a : b;  // 条件 ? 真值 : 假值
```

### 2. 运算符优先级（常用）

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1 | `()` `[]` `->` `.` | 左到右 |
| 2 | `++` `--` `!` `~` `*` `&` `sizeof` | 右到左 |
| 3 | `*` `/` `%` | 左到右 |
| 4 | `+` `-` | 左到右 |
| 5 | `<<` `>>` | 左到右 |
| 6 | `<` `<=` `>` `>=` | 左到右 |
| 7 | `==` `!=` | 左到右 |
| 8 | `&` | 左到右 |
| 9 | `^` | 左到右 |
| 10 | `\|` | 左到右 |
| 11 | `&&` | 左到右 |
| 12 | `\|\|` | 左到右 |
| 13 | `?:` | 右到左 |
| 14 | `=` `+=` `-=` 等 | 右到左 |

> **建议**：不确定优先级时，用括号明确优先级！

### 3. 短路求值
```cpp
if (a != nullptr && a->value > 0) {  // 若 a 为空，右侧不会执行
    // ...
}

if (b == 0 || check_division(b)) {   // 若 b 为 0，右侧不会执行
    // ...
}
```

## 💻 代码示例

```cpp
#include <iostream>

int main() {
    int a = 10, b = 3;
    
    // 算术运算
    std::cout << "a / b = " << a / b << std::endl;     // 3（整数截断）
    std::cout << "a % b = " << a % b << std::endl;     // 1
    
    // 自增的区别
    int x = 5;
    int y = ++x;   // 先增后赋值：x=6, y=6
    int z = x++;   // 先赋值后增：z=6, x=7
    
    // 位运算
    unsigned int flags = 0b1010;
    flags |= 0b0100;   // 设置第 2 位
    flags &= ~0b0010;  // 清除第 1 位
    
    // 三目运算符
    int max = (a > b) ? a : b;
    
    return 0;
}
```
