## 📚 核心知识点

### 1. 容器对比

| 容器 | 底层结构 | 有序 | 重复键 | 查找 | 插入 | 适用场景 |
|------|----------|------|--------|------|------|----------|
| `set` | 红黑树 | 是 | 否 | O(log n) | O(log n) | 有序唯一集合 |
| `map` | 红黑树 | 是 | 否 | O(log n) | O(log n) | 有序字典 |
| `multiset` | 红黑树 | 是 | 是 | O(log n) | O(log n) | 有序可重复 |
| `multimap` | 红黑树 | 是 | 是 | O(log n) | O(log n) | 有序多值字典 |
| `unordered_set` | 哈希表 | 否 | 否 | 平均 O(1) | 平均 O(1) | 快速查找集合 |
| `unordered_map` | 哈希表 | 否 | 否 | 平均 O(1) | 平均 O(1) | 快速查找字典 |

### 2. set / multiset
```cpp
#include <set>

std::set<int> s = {3, 1, 4, 1, 5};  // {1, 3, 4, 5}

// 插入
s.insert(2);           // {1, 2, 3, 4, 5}
s.emplace(6);          // 原地构造

// 查找
auto it = s.find(3);   // 返回迭代器，找不到返回 s.end()
s.count(3);            // 存在返回 1，不存在返回 0
s.contains(3);         // C++20，返回 bool

// 范围查询
auto range = s.equal_range(3);  // 返回 pair<lower_bound, upper_bound>
s.lower_bound(3);      // 第一个 >= 3 的位置
s.upper_bound(3);      // 第一个 > 3 的位置

// multiset（允许重复）
std::multiset<int> ms = {1, 2, 2, 3};
ms.count(2);           // 返回 2
```

### 3. map / multimap
```cpp
#include <map>

std::map<std::string, int> scores;

// 插入
scores["Alice"] = 85;           // 插入或更新
scores.insert({"Bob", 90});     // C++11 列表初始化
scores.emplace("Charlie", 78);  // 原地构造

// C++17 try_emplace（如果不存在才插入）
scores.try_emplace("Alice", 95);  // Alice 已存在，不更新

// 访问
int alice_score = scores["Alice"];  // 不存在会默认构造！
auto it = scores.find("Bob");
if (it != scores.end()) {
    std::cout << it->second;
}

// 安全访问（C++17）
if (auto [it, inserted] = scores.insert({"Dave", 88}); inserted) {
    std::cout << "Inserted";
}

// 遍历（按键的升序）
for (const auto& [name, score] : scores) {  // C++17 结构化绑定
    std::cout << name << ": " << score << std::endl;
}
```

### 4. unordered_set / unordered_map
```cpp
#include <unordered_map>

std::unordered_map<std::string, int> hash_map;

hash_map["apple"] = 5;
hash_map["banana"] = 3;

// 自定义哈希函数
struct Person {
    std::string name;
    int age;
};

struct PersonHash {
    size_t operator()(const Person& p) const {
        return std::hash<std::string>()(p.name) ^ std::hash<int>()(p.age);
    }
};

struct PersonEqual {
    bool operator()(const Person& a, const Person& b) const {
        return a.name == b.name && a.age == b.age;
    }
};

std::unordered_set<Person, PersonHash, PersonEqual> people;
```

### 5. 自定义比较器
```cpp
// 自定义排序规则
struct Descending {
    bool operator()(int a, int b) const {
        return a > b;  // 降序
    }
};

std::set<int, Descending> desc_set = {1, 2, 3, 4, 5};
// 遍历顺序：5, 4, 3, 2, 1

// Lambda 比较器（C++11）
auto cmp = [](int a, int b) { return a > b; };
std::set<int, decltype(cmp)> s(cmp);
```

## 💻 代码示例

```cpp
#include <iostream>
#include <map>
#include <unordered_map>
#include <string>

int main() {
    // 统计单词频率
    std::string text = "apple banana apple cherry banana apple";
    std::unordered_map<std::string, int> freq;
    
    std::istringstream iss(text);
    std::string word;
    while (iss >> word) {
        ++freq[word];
    }
    
    // 按频率排序输出
    std::map<int, std::vector<std::string>> sorted;
    for (const auto& [w, c] : freq) {
        sorted[c].push_back(w);
    }
    
    for (auto it = sorted.rbegin(); it != sorted.rend(); ++it) {
        std::cout << "Count " << it->first << ": ";
        for (const auto& w : it->second) {
            std::cout << w << " ";
        }
        std::cout << std::endl;
    }
    
    return 0;
}
```
