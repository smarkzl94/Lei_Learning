## 📚 核心知识点

### 1. 参数服务器简介

参数服务器是一个共享的字典，用于存储配置数据：
- 机器人尺寸、重量等静态参数
- PID 控制器参数
- 算法阈值和配置

特点：
- 全局可见，所有节点可访问
- 适合存储静态或缓慢变化的配置
- **不适合**存储高频变化的数据（用 Topic）

### 2. ROS1 参数操作

#### 命令行
```bash
# 列出参数
rosparam list

# 获取参数
rosparam get /turtlesim/background_r

# 设置参数
rosparam set /turtlesim/background_r 150

# 删除参数
rosparam delete /param_name

# 导出到文件
rosparam dump params.yaml

# 从文件加载
rosparam load params.yaml
```

#### C++ 代码
```cpp
#include <ros/ros.h>

int main(int argc, char** argv) {
    ros::init(argc, argv, "param_demo");
    ros::NodeHandle nh;
    ros::NodeHandle private_nh("~");  // 私有命名空间
    
    // 1. 设置参数
    nh.setParam("/global_param", 100);
    private_nh.setParam("private_param", 200);
    
    // 2. 获取参数
    int value;
    if (nh.getParam("/global_param", value)) {
        ROS_INFO("Got: %d", value);
    }
    
    // 3. 带默认值的获取
    double kp = nh.param("kp", 0.5);  // 如果参数不存在，返回默认值 0.5
    
    // 4. 获取所有参数
    std::map<std::string, std::string> params;
    nh.getParamNames(params);
    
    // 5. 检查参数是否存在
    if (nh.hasParam("my_param")) {
        // ...
    }
    
    // 6. 删除参数
    nh.deleteParam("old_param");
    
    return 0;
}
```

#### 参数文件（YAML）
```yaml
# config/robot_params.yaml
robot:
  name: "my_robot"
  max_speed: 1.0
  
controller:
  pid:
    kp: 0.5
    ki: 0.1
    kd: 0.05
    
sensors:
  laser:
    range_min: 0.1
    range_max: 30.0
    angle_min: -1.57
    angle_max: 1.57
```

#### Launch 文件加载
```xml
<launch>
  <rosparam file="$(find my_pkg)/config/robot_params.yaml" command="load" />
  
  <node pkg="my_pkg" type="my_node" name="controller">
    <param name="kp" value="0.8" />
  </node>
</launch>
```

### 3. ROS2 参数操作

#### 命令行
```bash
# 列出参数
ros2 param list

# 获取参数
ros2 param get /turtlesim background_r

# 设置参数
ros2 param set /turtlesim background_r 150

# 描述参数（获取详细信息）
ros2 param describe /turtlesim background_r

# 导出参数
ros2 param dump /turtlesim > params.yaml

# 加载参数
ros2 param load /turtlesim params.yaml
```

#### C++ 代码
```cpp
#include <rclcpp/rclcpp.hpp>

class ParamNode : public rclcpp::Node {
public:
    ParamNode() : Node("param_demo") {
        // 声明参数（带默认值）
        declare_parameter("kp", 0.5);
        declare_parameter("ki", 0.1);
        declare_parameter("kd", 0.05);
        
        // 获取参数
        double kp = get_parameter("kp").as_double();
        RCLCPP_INFO(get_logger(), "kp = %f", kp);
        
        // 设置参数
        set_parameter(rclcpp::Parameter("kp", 0.8));
        
        // 添加参数变更回调
        param_callback_handle_ = add_on_set_parameters_callback(
            std::bind(&ParamNode::onParamChange, this, std::placeholders::_1));
    }
    
private:
    rcl_interfaces::msg::SetParametersResult onParamChange(
        const std::vector<rclcpp::Parameter>& params) {
        for (const auto& param : params) {
            RCLCPP_INFO(get_logger(), "Param changed: %s", param.get_name().c_str());
        }
        
        rcl_interfaces::msg::SetParametersResult result;
        result.successful = true;
        return result;
    }
    
    rclcpp::node_interfaces::OnSetParametersCallbackHandle::SharedPtr 
        param_callback_handle_;
};
```

### 4. 动态参数配置（ROS1）

```bash
# 安装
cd ~/catkin_ws/src
git clone https://github.com/ros/dynamic_reconfigure.git
cd ~/catkin_ws && catkin_make

# 创建配置
cd src/my_pkg
mkdir cfg
cat > cfg/Controller.cfg << 'EOF'
#!/usr/bin/env python
from dynamic_reconfigure.parameter_generator_catkin import *

gen = ParameterGenerator()

gen.add("kp", double_t, 0, "Proportional gain", 0.5, 0, 10)
gen.add("ki", double_t, 0, "Integral gain", 0.1, 0, 10)
gen.add("kd", double_t, 0, "Derivative gain", 0.05, 0, 10)

gen.generate("my_pkg", "controller_node", "Controller")
EOF
chmod +x cfg/Controller.cfg
```

```cpp
#include <dynamic_reconfigure/server.h>
#include <my_pkg/ControllerConfig.h>

void callback(my_pkg::ControllerConfig &config, uint32_t level) {
    ROS_INFO("Reconfigure: kp=%f, ki=%f, kd=%f",
             config.kp, config.ki, config.kd);
}

int main(int argc, char **argv) {
    ros::init(argc, argv, "dynamic_controller");
    
    dynamic_reconfigure::Server<my_pkg::ControllerConfig> server;
    server.setCallback(callback);
    
    ros::spin();
    return 0;
}
```

## ❓ 常见问题

**Q: 参数和 Topic 的区别？**
A: 参数适合静态/准静态配置；Topic 适合动态数据流。参数变化频率低，Topic 数据频率高。

**Q: 私有参数 `~param` 是什么意思？**
A: `~` 表示节点私有命名空间。如节点名是 `/controller`，`~kp` 就是 `/controller/kp`。
