## 📚 核心知识点

### 1. 自定义消息（.msg）

```bash
my_pkg/
├── msg/
│   ├── RobotStatus.msg
│   └── SensorData.msg
```

```
# msg/RobotStatus.msg
Header header
string robot_id
float32 battery_percent
bool is_moving
geometry_msgs/Pose current_pose
```

```
# msg/SensorData.msg
Header header
float32[] readings
string sensor_type
uint8 status
```

### 4. ROS1 配置

#### package.xml
```xml
<build_depend>message_generation</build_depend>
<exec_depend>message_runtime</exec_depend>

<!-- 如果消息用了其他包的消息 -->
<depend>std_msgs</depend>
<depend>geometry_msgs</depend>
```

#### CMakeLists.txt
```cmake
find_package(catkin REQUIRED COMPONENTS
  roscpp
  std_msgs
  geometry_msgs
  message_generation
)

# 添加消息文件
add_message_files(
  FILES
  RobotStatus.msg
  SensorData.msg
)

# 添加服务文件
add_service_files(
  FILES
  GetRobotInfo.srv
)

# 添加动作文件
add_action_files(
  FILES
  NavigateTo.action
)

# 生成消息
generate_messages(
  DEPENDENCIES
  std_msgs
  geometry_msgs
)

catkin_package(
  CATKIN_DEPENDS message_runtime
)
```

### 5. ROS2 配置

#### package.xml
```xml
<buildtool_depend>rosidl_default_generators</buildtool_depend>
<exec_depend>rosidl_default_runtime</exec_depend>
<member_of_group>rosidl_interface_packages</member_of_group>

<depend>std_msgs</depend>
<depend>geometry_msgs</depend>
```

#### CMakeLists.txt
```cmake
find_package(rosidl_default_generators REQUIRED)

rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/RobotStatus.msg"
  "msg/SensorData.msg"
  "srv/GetRobotInfo.srv"
  "action/NavigateTo.action"
  DEPENDENCIES std_msgs geometry_msgs
)
```

### 6. 使用自定义消息

#### ROS1 C++
```cpp
#include <my_pkg/RobotStatus.h>

// Publisher
ros::Publisher pub = nh.advertise<my_pkg::RobotStatus>("status", 10);

my_pkg::RobotStatus msg;
msg.robot_id = "robot_001";
msg.battery_percent = 85.5;
msg.is_moving = true;
pub.publish(msg);

// Subscriber
void callback(const my_pkg::RobotStatus::ConstPtr& msg) {
    ROS_INFO("Robot: %s, Battery: %.1f%%",
             msg->robot_id.c_str(), msg->battery_percent);
}
ros::Subscriber sub = nh.subscribe("status", 10, callback);
```

#### ROS2 C++
```cpp
#include <my_pkg/msg/robot_status.hpp>

// Publisher
auto pub = create_publisher<my_pkg::msg::RobotStatus>("status", 10);

my_pkg::msg::RobotStatus msg;
msg.robot_id = "robot_001";
msg.battery_percent = 85.5;
msg.is_moving = true;
pub->publish(msg);
```

## ❓ 常见问题

**Q: 修改了 .msg 文件但代码中看不到变化？**
A: 需要重新编译消息包，然后重新 source 环境。有时需要清理 build 目录。

**Q: 自定义消息包应该在 src 的第一层还是放在功能包内？**
A: 推荐独立成一个包（如 `my_msgs`），放在 src 第一层，被其他所有包依赖。

**Q: 消息字段命名有什么规范？**
A: 小写 + 下划线（snake_case），与 ROS 官方消息风格一致。
